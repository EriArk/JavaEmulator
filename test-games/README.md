# Legacy test fixtures

This directory contains historical development fixtures, not games bundled
with the AbyssME APK or a recommended public game library.

| Files | Provenance status |
| --- | --- |
| `Stalker.jar`, `Stalker.jad` | Original download source and redistribution terms are not documented here. |
| `KoalaMines.jar`, `KoalaMines.jad` | Original download source and redistribution terms are not documented here. |
| `extracted/stalker-*.png` | Extracted from the Stalker fixture; the same unresolved provenance applies. |

The emulator's Apache-2.0 license does not establish permission to redistribute
these games or images. Whether to document their permissions or replace them
is awaiting a maintainer decision in
[#5](https://github.com/EriArk/JavaEmulator/issues/5). No legal conclusion about
the original authors' terms is asserted here. Do not copy these files into
release bundles based on the repository license alone.

Future fixtures should include an authoritative source, applicable license or
permission, version/checksum and the behavior they exercise. Prefer small,
source-available examples with explicit redistribution terms.

The separately installed games used for the beta.2 website screenshots have
their source links listed in the [capture manifest](../screenshots/website-beta2/manifest.json);
their JARs are not part of that screenshot pack.
