# Palm OS on Android

The Palm OS tile opens the normal AbyssME library. Start by importing and opening a device ROM. Complete Palm's first-run digitizer setup, then choose **Save and exit** in the game menu or select **More → Save Palm session**. Opening a game uses a copy of that prepared device. Each game saves its own RAM and machine state under its package identity and selected ROM. Opening a different supported ROM selects that model for subsequent launches. The app can retain both profiles.

Import a PRC directly or put a game's PRC and companion PDBs together in a ZIP. For archives containing multiple applications, the launcher offers their Palm database names. Native Android handles display settings, virtual and physical controls, stylus coordinates and the DragonBall speaker. A native ARM64 uARM process runs supported Palm OS 5 machines. It streams guest frames and stereo PCM to the Android activity and accepts stylus, mapped keys and speed changes from the shared controls. An older Palm OS machine such as the m515 uses the bundled CloudpilotEmu WebView runtime. Both paths work offline.

For an ARM64 combined debug build run `bash engines/palm/prepare.sh` and `bash engines/palm/build-native.sh`, then enable `-PpalmProbe=true` alongside the other handheld flags. The preparation script verifies the release archive checksum before extracting the two WASM cores and runtime scripts. The native build uses CMake, Ninja and NDK r28c. Set `ANDROID_NDK_HOME` to the NDK or `ANDROID_HOME` to the SDK. Set `PALM_SOURCE_DIR` to reuse a checkout of the pinned revision. Gradle packages the resulting executable under the APK native library directory. The OS 4 adapter uses the raw display canvas, stylus input, snapshot encoder and PWM events from this pinned version. A core upgrade needs a compatibility check of those interfaces. [CloudpilotEmu 2.3.0 source](https://github.com/cloudpilot-emu/cloudpilot-emu/tree/2.3.0) · [Embedded API](https://cloudpilot-emu.github.io/embedded/).

The Retroid run covers the m515 with Space Trader on Palm OS 4.1 and m505 device startup. Tungsten E2 needs both NOR and a complete 34,603,008-byte raw NAND for the stock ROM. Bejeweled 2.1 ran on the E2 with PCM sound. Launching its PRC with a prepared E2 firmware session took about five seconds from Android's open-file request to the title screen. The native core reads existing WebView-created game sessions and writes new checkpoints in the same format. Removable cards, Graffiti handwriting entry, HotSync and other peripherals remain unverified. [Device checks](../../docs/checks/2026-11-21-palm.md).
