# Store metadata

This directory was inherited from J2ME Loader. The English text now describes
AbyssME; other translations, icons and store screenshots may still describe
upstream and have not been approved as an AbyssME store listing.

There is no automated store publication. Before using these assets for a store
submission, review branding, translations, current screenshots and both APK
variants. Do not present inherited screenshots as current AbyssME captures.

The maintained public description is the [repository README](../README.md).

[screenshots/website-beta2](../screenshots/website-beta2).
