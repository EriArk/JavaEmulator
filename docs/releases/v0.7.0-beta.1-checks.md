2026-10-28. Candidate `0.7.0-beta.1`, code **313**. Signed publication/update
results are recorded below after verification; preparation alone is not release.

## Scope

Cumulative audio, touch controls and localization changes after 0.6.0 Revision 1,
plus [#47's modern SIS preflight repair](../checks/2026-10-28-ngage-platform-preflight.md).

## Rotation Finding

Two 216-case Debug readiness runs each had one failed rotation-placement check.
The first stale result was centered after returning to portrait. The diagnostic
retry showed landscape dialog resources (1240x1032) with the old bottom gravity.
An isolated optimized check and isolated Debug check passed between these runs;
that did not establish a fix.

Repair the shared menu by reconciling orientation, display dimensions and density
at layout traversal as well as configuration callbacks. Cache the last geometry
so an unchanged layout does not continuously request another resize. Keep the
existing detached-window and lifecycle guards. Expand the regression to three
round trips, keeping its placement assertions. All **12 menu-layout checks pass**
after repair (`build/issue47/retroid-rotation-repaired.log`, 20.283s).

Earlier failures remain in `retroid-release-regressions.log` and
`retroid-release-final.log` under `build/issue47`; do not report uninterrupted green.

Final broad Retroid run: **216 tests pass**, zero failures/skips, 252.544 seconds
(`build/issue47/retroid-verified.log`). Covers Java audio and Canvas lifecycle,
touch mapping/feedback and preview state, Java/Mophun/Symbian input fixtures,
shared menus, language choices, localized native imports, Social presentation
and large-text layouts. It includes the repeated rotation regression after the
repair; it does not substitute for complete games or a new network match.

## Signed Upgrade and Smoke Checks

The production-signed APK was installed with `adb install -r` over the official
code-312 app on Retroid Pocket Classic / Android 14. Package/version inspection
confirms code 313. All **329 readable external file hashes** match before and
after the update, before starting the new version. Internal files and two
inaccessible converted Mophun directories were not hashed; this is not a claim
to have inspected every save. No uninstall or app-data clear was used.

In the signed app, the Java library still contains 34 games. Bounce Tales reaches
its chapter-one scene; the shared game menu, Controls and graphical touch mapping
editor open. A draft layout change was cancelled, not saved over the user's
profile. Deep Abyss T300 and Snakes reach their title/main-menu screens. Shared
menus and centered exit confirmations work, returning to the library. These are
startup/UI smoke checks, not full-game acceptance. Local screenshots and upgrade
hash logs are under `build/issue47/signed-*` and `upgrade-{before,after}.txt`.

The signed Settings language picker switches to Japanese and Simplified Chinese;
both Settings screens render correctly in the near-square landscape viewport.
The original System default selection is restored after the check. This is
visual switching evidence, not native-speaker validation.

## Limits

These checks distinguish Debug/rehearsal fixture coverage from production-signed
startup/UI checks. They are not subjective audio review, physical-button comfort,
complete games, sustained performance or new internet multiplayer acceptance.
Earlier Android 11 localization checks remain dated evidence, not a fresh emulator
run for the 0.7 APK. New languages beyond the selected eight remain deferred.
