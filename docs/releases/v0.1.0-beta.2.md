# AbyssME 0.1.0 Beta 2

Beta 2 adds an independently installable Phone variant while keeping the
controller-first Handheld behavior unchanged.

## Choose a Build

- `AbyssME-0.1.0-beta.2-fdroid-release.apk`: landscape-only Handheld build for
  physical controllers, ES-DE, Beacon, and Android gaming devices.
- `AbyssME-0.1.0-beta.2-phone-release.apk`: Phone build with automatic rotation,
  a compact portrait library, direct MIDP touch input, and an on-screen keypad.

Both variants require Android 10 or newer and can be installed together. They
use independent app data and per-game settings.

## Phone Controls

- Virtual numbers, directions, fire, soft keys, and emulator Menu are enabled
  by default for newly installed games.
- Touch input and the virtual keypad can be toggled separately per game.
- Key layout, opacity, colors, haptics, and orientation remain configurable.
- The compatibility test preserves the Phone input settings.

## Shared Improvements

- Version and package names now distinguish Handheld and Phone installations.
- The release signing path is resolved consistently from the project root.
- The README and launcher integration guide document both packages.
