## Retroid checks

Device: Retroid Pocket Classic, Android 14, with native ARM64 and ARM32 support.

- The 116 combined Android checks and Diamond Rush xBRZ smoke from the
  [implementation report](../checks/2026-11-14-graphics-profiles.md) retain their
  original scope. Runtime implementation is unchanged apart from release version.
- **85 fresh ARMv7 checks pass:** independent graphics/control profiles,
  inheritance/migration, serialization, Try/Keep/Undo, profile editor and library
  backups, plus actual 32-bit process/native-library and unavailable-tab checks.
  83 passed in the initial run; Android's first-launch DeprecatedAbiDialog covered
  the two UI confirmation dialogs. After acknowledging it, both UI tests passed
  on retry without source changes.
- The final signed ARM64 APK upgrades Beta 6 without uninstalling. All **335
  readable external library files** retain their hashes immediately after install,
  including a backed-up legacy-format profile fixture.
- In the signed app UI, Graphics profiles and Control profiles are separate.
  Saving xBRZ in graphics defaults preserves the old named LCD definition and
  the control catalog. The actual game's profile panel resolves the migrated
  graphics identity and retains existing graphics as overrides. Resetting only
  graphics overrides and using **Keep** saves `RetroShader=1`, the independent
  graphics metadata and an empty graphics-override object while retaining its
  control assignment. This also exercises reflected/Gson fields after R8.
- The signed ARMv7 switch preserves all **335 readable external files** present
  immediately before install and retains the selected graphics/control metadata.

Both signed APKs render the Asphalt 3 title screen with the inherited xBRZ
profile after a fresh process launch. This is a shader/profile smoke check,
not another race, physical-input or audio acceptance run. Temporary profile
catalogs and the game's original configuration were restored byte for byte.
Normal app use changed database/cache files and the game's RMS registry header;
no claim of unchanged runtime-generated files is made. Returning to signed ARM64
preserves all **333 readable external files** present at that install boundary.
The temporary instrumentation packages were removed.

## Downloads and limits

All six draft asset names, sizes and GitHub SHA-256 digests match local staging.
Both APKs and checksums downloaded from the authenticated draft match byte for
byte. Both APKs and checksums were also downloaded from unauthenticated public URLs;
all hashes match. [GitHub prerelease](https://github.com/EriArk/JavaEmulator/releases/tag/v0.7.0-beta.7).

The readable-file snapshots are not exhaustive backups of inaccessible converted
folders or private phone storage. No exclusively 32-bit/low-memory handset,
complete-game, sustained thermal/performance, audible-output, physical-button
or new real Symbian/N-Gage game acceptance is claimed. Inputs were injected.
Existing engine/multiplayer limitations remain.

Local build logs, commands, R8 mappings, artifact inventories, signing results,
upgrade snapshots and private captures are retained under
`build/releases/0.7.0-beta.7/`.
