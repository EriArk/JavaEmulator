# 0.3.0-beta.2 Release Verification

**Withheld candidate, not a published release.** Final library provisioning
found that installing an unrelated SIS game could hide a registered N-Gage
card. The tag is retained as historical source; beta.3 fixes the shared cause.
The observations below describe the withheld APKs, not beta.3 verification.

Date: 2026-10-15. Version code **301**, Android 10+, arm64-v8a.
This document records final signed-build checks separately from development
instrumentation. Publication is recorded below after asset verification.

## Build and Source Materials

- Clean combined build with `-PsymbianRelease=true` and
  `-PsymbianSourceDir=build/symbian-source-check`: both release APKs,
  `verifyProductionApks`, both release lint tasks and both JVM suites passed.
- JVM: **25 passed per variant**, zero failures/errors. Lint: zero errors,
  **402 Handheld / 409 Phone warnings**. This is not a warning-free build.
- Both production APK guards confirmed engine/notices inclusion and absence of
  private games, phone dumps, old sound banks and removed legacy engine payloads.
- Both APKs retain the previous release signing certificate SHA-256:
  `722b6f8e74090bd3895eb0bc76433333c637e881758fc10ac276dd214499c38f`.
- Android dependency inventory/source preparation reran offline successfully:
  **118 artifacts**, no unresolved source entries. The **49** pinned native
  archives matched `engines/symbian/source-lock.json`. That pin and its source
  bundle are unchanged since beta.1; the verified bundle is reused, not repinned.
- The build uses the exported/restored native source tree verified for beta.1.
  A second fresh restoration was not performed in this pass. App-owned host
  changes are in the new matching app source archive.
- Local logs: `build/beta2-release-build.txt`, `build/beta2-dependency-sources.txt`.
  They are maintainer evidence, not public download assets.

## Final Signed APKs on Retroid

Physical Retroid Pocket Classic, Android 14, 1240x1080. The checks below use ADB
touch/key injection and inspected screenshots, not a person's physical-button
or audio-listening acceptance.

- Handheld upgraded the existing code-300 package with `adb install -r`.
  All **22 shell-readable external files** matched their pre-upgrade SHA-256
  values before first launch. Files inaccessible to the shell were not hashed.
  The existing Asphalt 3D, Deep Abyss and Snakes library entries remained visible.
- Phone also upgraded code 300 with `adb install -r`; its existing Snakes entry
  remained visible. Full private-data byte comparison was not available.
- The actual Handheld public importer installed Java games from a ZIP, a direct
  Mophun file, the supplied N95 ROM/RPKG ZIP and a three-item SIS/SISX archive.
  The native queue reported three completed installs and no install errors;
  this does not prove that every installed package is launchable/indexed.
- Age of Empires II reached its menu; Ghost Recon reached its title screen;
  Deep Abyss T300 reached its animated menu; 3D miniGolf reached its language
  screen. Shared game menus opened and confirmed exit returned to the library.
  These are startup/menu checks, not gameplay, save or full-game acceptance.
- In signed Phone, both Java Display/Screenshot switches were turned off and
  Menu remained reachable. Numeric and Gamepad decks were applied through
  Try / Keep. Ghost Recon rendered with the Gamepad deck and menu-only chrome.
- Signed Phone's tactile-feedback trial was kept; Android's vibration service
  recorded a completed **CLICK, 46 ms** request from the production Phone package.
  Perceived strength is not verified (the service reported scale 0.00).
- Fresh captures are under `screenshots/releases/v0.3.0-beta.2/`.
