# AbyssME 0.4.0 Beta 2

One APK for Android phones and handhelds, with Java, Mophun and experimental
Symbian / N-Gage. Android 10 or newer, arm64-v8a. Games and firmware are not
included. Version code: 307.

## What's New

- **Three visual styles:** Classic, Retro LCD and High contrast. Choose a style
  separately from Light / Dark / System brightness. The library, menus,
  controller mapper and modern touch buttons share the selected palette.
- **Visual touch layout editor:** open Controls > Edit touch layout to move or
  resize control blocks and choose Phone or Gamepad, button theme and opacity.
  Portrait and landscape placements are separate for each game. Use layout
  feeds the existing Try changes / Keep changes / Undo workflow; Cancel leaves
  the current layout alone. Blocks stay outside the game area.
- **A denser small-screen library:** more room for artwork on near-square
  displays, compact list rows, adaptable filters and retained controller focus.
- **Custom artwork for Symbian / N-Gage:** select separate covers and icons from
  the game's Artwork menu, just as for Java and Mophun. Use automatic resets
  either image independently. Refreshing the native library keeps your choices.
- **Artwork travels with phone backups:** custom covers and icons are restored
  alongside the virtual phone, games, saves and settings. Restoring creates a
  separate phone and does not overwrite the original.

## Updating and Moving Data

Install `AbyssME-0.4.0-beta.2.apk` over the unified app or former Handheld app.
Do not uninstall first. The old Phone app remains a separate installation;
use [Library transfer](../LIBRARY_TRANSFER.md#moving-from-abyssme-phone) and check
your saves before removing it.

New Symbian whole-phone backups use format version 2 and require Beta 2 or
newer on the receiving device. Older version-1 backups still restore. Java /
Mophun backups remain separate. Favorites, play history and app-wide preferences
are not part of a Symbian phone backup.

## Scope and Limits

This update focuses on presentation, controls and transfer, not new emulator
compatibility guarantees. Symbian / N-Gage remains experimental; Asphalt 3 cold
relaunch is still unreliable. The legacy Java keypad editor is unchanged.
Physical-controller comfort, Android 16, audio quality and complete campaigns
are not certified by automated checks.

See [verification](v0.4.0-beta.2-checks.md) and
[current status](../PROJECT_STATUS.md) for evidence and availability. The matching
app source, dependency sources and pinned Symbian sources accompany the APK.
Use `SHA256SUMS.txt` to verify downloaded files.
