# AbyssME 0.7.0 Beta 2

A maintenance beta for Java, Mophun and experimental Symbian/N-Gage on Android
phones and handhelds. One adaptive ARM64 APK; Android 10 or newer.

## What Changed

- Improve Java compatibility with legacy boolean-return bytecode. SimCity
  Metropolis now passes its previous Android verifier error and reaches the
  new-game introduction. Existing games rebuild their executable cache as needed;
  retained JARs and saves are not replaced.
- Recognize explicit uncommon Java screen sizes in game metadata and filenames.
  Keep manual custom width/height in advanced game settings. The physical D-pad
  center button now defaults to Fire, without overriding custom mappings.
- Make Symbian Portrait/Landscape trials select a mode that the virtual phone
  actually supports. Preserve its physical panel and compatibility modes; fix
  the reproduced Fruitz Portrait startup panic. Landscape with Fit keeps aspect
  ratio, but may leave borders, and games can select their own orientation.
- Initialize Symbian sensor events on Android's main looper. Repair shared native
  pause/resume, file-handle and guest-memory fault handling, and avoid querying
  the paused guest while previewing LCD settings.
- Add a shared launch-error screen with manual Retry and Exit game. Rejected
  Symbian display modes can be retried with Original as an unsaved preview.
  Settings trials survive menu/background transitions more safely.
- Import a complete registered virtual phone from an EKA2L1 folder or ZIP through
  Library transfer, including installed games, components and saves. Imports
  create a separate copy rather than merging into an existing phone.
- Retry unfinished Java/Mophun library transfers without recopying completed
  games or replacing their newer saves. Prepare backup ZIPs locally before
  writing to the chosen document. New UI copy covers all eight supported languages.

## Install

Download **AbyssME-0.7.0-beta.2.apk**, version code **315**. It updates the official
unified app in place. Back up valuable saves first; do not uninstall to update.
The legacy separate Phone app still needs the in-app backup/restore migration.
Games, firmware and personal accounts are not included.

App source and dependency/Symbian source bundles accompany the APK. The unchanged
dependency bundles retain their Beta 1 filenames and hashes; current host repairs
and native patches are in the Beta 2 app-source archive.

## Verification and Limits

The preceding Retroid sample covers ten Java JARs and ten Symbian packages, with
startup, menus and gameplay distinguished. It includes 46 focused Android tests,
five converter JVM tests and N95/EKA1 mode cycles; see the
[sample matrix](../checks/2026-11-02-game-sample.md). Release-specific build,
signature and upgrade results are recorded in the
[verification report](v0.7.0-beta.2-checks.md).

Symbian/N-Gage remains experimental. Sky Force Reloaded has black output,
Labyrinth Touch has incomplete rendering after its sensor initialization fix,
and Tilt Blocks has no initial frame in the tested setup. Fruitz reaches its
menu but gameplay is not confirmed. N95/Asphalt 3 cold launch/resume is still
unreliable. These problems are deferred to subsequent compatibility work.

This release does not add arbitrary Symbian resolutions or universal widescreen.
Launch recovery cannot intercept every native crash, hang or black screen.
Physical tilt, complete games, audio quality and new internet matches are not
certified by these checks. Java Bluetooth multiplayer remains early experimental
with low compatibility. Final backup writes depend on the document provider;
keep an older backup and use a new filename.
