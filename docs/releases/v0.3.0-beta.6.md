# AbyssME 0.3.0 Beta 6

Java, Mophun and experimental Symbian / N-Gage in one Android app.
Android 10+, arm64-v8a. Version code **305**.

## Downloads

- **[Handheld APK](https://github.com/EriArk/JavaEmulator/releases/download/v0.3.0-beta.6/AbyssME-0.3.0-beta.6-handheld.apk):** landscape, physical controls, no touch keypad.
- **[Phone APK](https://github.com/EriArk/JavaEmulator/releases/download/v0.3.0-beta.6/AbyssME-0.3.0-beta.6-phone.apk):** portrait/landscape, Phone and Gamepad touch layouts.

Install over the same variant to keep its library, settings and saves. The two
variants have independent data. Games and firmware are not bundled.

## New Since Beta 5

- **Emulation speed:** separate per-game presets of 50%, 75%, 100%, 125%, 150%
  and 200% in **Game menu > More > Emulation speed** and Display. 100% is normal.
  Java, Mophun and Symbian use scaled guest time, rather than relabeling an FPS
  setting. Changes can be tried live, kept or undone.
- **Frame rate limit on every platform:** Mophun and Symbian / N-Gage now have
  the same Unlimited / 15 / 20 / 25 / 30 / 50 / 60 presets as Java. Existing
  native profiles retain 60 FPS; saved Java limits are preserved.
- **Existing Java games:** where the original classes are available in the
  installed JAR, executable code is refreshed in private cache for the new
  timing support. Original game files and saves are not rewritten. Older
  resource-only imports still launch, but need their original JAR reimported
  to enable speed control.
- **Symbian reliability:** bounded file transfers by the guest buffer and file
  length, preserved partial reads, and synchronized application lookup/launch.

## Known Limits

Speed control is experimental. It adjusts guest clocks and supported waits,
not the physical CPU. Games paced by busy loops, frame counts or audio may not
follow the percentage exactly. A frame cap or slow hardware can also limit
acceleration. Music and audio playback remain at normal tempo; audio/video
synchronization away from 100% is not guaranteed. Return to 100% for normal use.

Symbian / N-Gage remains experimental. Native Asphalt cold relaunch is still
unreliable; this release does not claim to fix every black screen. Checkpoints
in individual games are not complete-game, controller, audio or save acceptance.

Matching app/dependency/native source bundles and SHA-256 checksums accompany
the APKs. See [release checks](https://github.com/EriArk/JavaEmulator/blob/main/docs/releases/v0.3.0-beta.6-checks.md).
