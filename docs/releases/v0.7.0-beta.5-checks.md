## Scope

The existing ARMv7 Java/Mophun target is being promoted to a separate beta APK.
The combined ARM64 target retains Symbian/N-Gage. About identifies the installed
distribution beside its version. No engine, minimum-Android, save-format or
network-protocol change is introduced; Beta 4 navigation fixes remain included.
The proposed Discord button is deferred: the FAQ invitation returned HTTP 404
on November 13. No replacement destination is assumed.

## Native ARMv7 acceptance on Retroid

Retroid Pocket Classic / Android 14 advertises `armeabi-v7a` and `zygote64_32`.
The isolated validation package runs natively as a **32-bit process**, with no
ARM translation. Its only private build overlay changes the Debug application
suffix to `.dualcheck.debug`, leaving official/user Debug installations separate.
The ARMv7 test APK also enables the existing optional production-M3G test sources.

**78 targeted Android tests pass (33.165s)**: process/ABI/backend loading, hidden
platform navigation and retained preferences, library import/backup, generated
audio/MIDI, Mophun scene/save, encrypted peer transport, M3G rasterizer, Help/About
and compatibility-editor navigation. This does not certify audible output or
multiplayer game compatibility.

Three isolated permitted-game checks then pass, with private screenshots reviewed:

- Deep Abyss 1.4: 22.943s; gameplay, pause/resume, save/export/restore and relaunch.
  `resume.sav` and `maxlevel.sav` retain hashes; resumed gameplay is visible.
- Diamond Rush 1.1.6: 65.636s; four RMS files retain hashes across backup/restore;
  gameplay is visible after relaunch.
- Asphalt 3 Street Rules 3D 1.1.5: 48.476s; a rendered race and input response are
  visible. A process-memory snapshot is retained, not a low-memory stress or
  sustained performance benchmark. This is the Java edition, not N95/Symbian.

The first two Deep Abyss attempts were blocked by Android's `DeprecatedAbiDialog`:
the focused system warning prevented the game from presenting its first frame.
The warning was captured and acknowledged; the subsequent game checks passed
without an engine change. The same warning appears on the final signed ARMv7
APK on this 64-bit-capable Android 14 device. ARM64 is recommended when supported.

## Upgrade and signed checks

An ARMv7-to-ARM64 Debug update preserves a three-game fixture, payload/config/save/
shared-file hashes, favorites/history and remembered Java/Mophun views. Separate
seed/verify phases pass (2.647s / 2.007s); saves in this fixture are synthetic.
Eight combined Help/About/navigation tests also pass on Retroid.

On API 30, a new isolated Android user installs the final signed ARMv7 APK, opens
its two-platform empty library, switches in place to the signed combined APK and
opens its four-platform library. This is translated emulator evidence. An initial
capture pass remained behind the keyguard and is not counted as UI acceptance;
the corrected pass explicitly unlocks the temporary user before inspection.
The emulator exited during user cleanup; after restarting and removing stale
AVD locks, the temporary user was removed and only Owner remained. The task
emulator was then stopped. This interruption is not counted as an app test pass.

The final signed ARMv7 APK upgrades the official Retroid installation from Beta 4
(code 318) to 319 without uninstalling; all 329 directly readable external file
hashes remain unchanged immediately after installation. The two-platform library
and About's ARMv7 label were inspected. Returning to the final combined APK
(code 319) also preserves all 329 readable hashes; the four-platform library and
previous Snakes N-Gage entry are visible again. The Retroid is left on ARM64.
Two converted Mophun directories are inaccessible to shell; the 329-file snapshot
is not an exhaustive backup of private/phone data.

## Limits and evidence retention

Native ARM32 execution on Retroid does not establish acceptance on exclusively
32-bit, low-memory phones. Android older than 10, sustained performance/thermal
behavior, listening/physical-controller comfort, complete games and broader
multiplayer compatibility remain unverified. N95 cold startup remains unresolved.
The source-only ARMv7 checkpoint remains historical; no old tag/asset is replaced.

Build, test, signing, installation and publication logs are retained locally under
`build/releases/0.7.0-beta.5/`. Its `private/` and device fixture/capture directories
are not release assets. No game, firmware, account or signing material is published.
