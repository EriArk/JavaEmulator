# 0.7.0 Beta 1 Revision 1

2026-10-28. Scope: issue [#46](https://github.com/EriArk/JavaEmulator/issues/46),
center game titles below library artwork. Version `0.7.0-beta.1-r1`, code **314**.
Published on the existing 0.7 Beta 1 page; signed checks and replacement results
are recorded below.

## Change

- Grid and Gallery titles use horizontal center gravity; List uses relative
  start alignment, including RTL layouts. Explicit text alignment and gravity
  are applied on every bind through the shared mode layout.
- Keep existing one/two-line limits, text size, card dimensions, ellipsis,
  artwork, selection and navigation. No new toggle, data migration or engine change.
- Add a focused same-ViewHolder mode-recycling regression for LTR and RTL;
  extend the existing Gallery format/recreation check with title gravity.
