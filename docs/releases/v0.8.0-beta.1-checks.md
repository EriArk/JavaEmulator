## Signed installation checks

- Android 11 emulator with ARM translation, ARM64. Installed the previous signed Beta 10, imported Sudoku J2ME and opened the game. Updating in place preserved the hashes of all 12 external library, fixture, configuration and RMS files. The signed launcher showed Java ME with the existing game by default. With empty platforms enabled, all 24 public tiles appeared. The supplied Challenger Tank cartridge opened in the Supervision host. After input the tank appeared on the road with the score counter.
- Retroid Pocket Classic, ARMv7. The Android 11 emulator rejected the 32-bit ABI, so this upgrade was checked on hardware. The signed ARMv7 APK updated the previous signed 32-bit Beta 10 and preserved 372 readable files at the install boundary. The process used armeabi-v7a and Sudoku J2ME opened at the board. Android showed its 32-bit compatibility notice. The temporary official package was removed. The original combined private installation remained on the device.
- Other individual games and all physical-controller layouts were not replayed for these final signed APKs. Earlier platform-specific device checks are indexed in [project status](../PROJECT_STATUS.md). A separate MRE replacement-backend probe on Retroid reached the first guest system call after 66 instructions. MRE is outside the published builds.
