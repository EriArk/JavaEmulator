# AbyssME 0.4.0 Beta 3 - Revision 1

Java, Mophun and experimental Symbian/N-Gage in one adaptive Android app.

## Updated Build

This is an update to the existing Beta 3 release, not a separate release page.
Use the **beta.3-r1** APK below (version code 309). The original Beta 3 assets
remain available as historical files; its source tag has not been rewritten.

## Changes

Retains Beta 3's LCD effects, screenshot options, platform filters, library
navigation and portable Symbian/N-Gage card titles.

- Configurable fast-forward: 1.5x, 2x, 3x and 4x targets, independently for each game.
- Assign a controller button or trigger, with Hold or Toggle behavior. The
  shortcut does not also press its game key.
- Toggle fast-forward from the game menu or the on-screen shortcut. The active
  shortcut remains accessible after the rest of the row hides; it can also be
  disabled in that game's settings.
- Return to the previous speed and frame cap when acceleration stops. Menus,
  backgrounding and controller disconnection cancel acceleration safely.
- Extend guest timing and audio-rate support to 4x across all three engines.

Open **Game menu > More > Fast-forward settings**, choose your options, then
**Try changes > Keep changes**. No button is reserved by default.

Actual acceleration depends on the game and device. This does not guarantee
skipping all in-game countdowns. Audio pitch changes with speed. Little Big City
and Green Farm have not been individually verified.
