`722b6f8e74090bd3895eb0bc76433333c637e881758fc10ac276dd214499c38f`.
Signing keys stayed outside the builder and upload bundle.

All 118 runtime artifact hashes per target match the pinned dependency bundle.

Commercial games, save files, credentials and private captures are not published.

## Android and signed-build checks

Retroid Pocket Classic, Android 14, native ARM64 and ARM32:

- **24 ARM64 instrumentation checks**: right-stick decoding/identification,
  profile round-trip, old defaults, mapper layouts/navigation, device lifecycle,
  fast-forward and Mophun/Symbian key boundaries.
- **24 ARMv7 checks** cover the shared controller suite, Mophun boundary and a
  native 32-bit process/library check. 22 passed initially; two focus-dependent
  UI tests were covered by Android's DeprecatedAbiDialog. After acknowledging
  that system dialog both passed on retry with unchanged source.
- Final signed ARM64 identifies right-stick Up in the mapper, saves it as key 5,
  retains left-stick Left as Left, and uses the right stick to confirm an actual
  Asphalt 3 menu. The persisted configuration matches the UI assignment.
- Switching to final signed ARMv7 retains that mapping. Left-stick motion changes
  the language selection and right-stick Up confirms it, using kernel uinput
  joystick events through Android's normal input delivery.
- Beta 8 to ARM64 Beta 9 preserves 374 readable external library files;
  ARMv7 switch preserves 363; return to ARM64 preserves 359.
  Hash comparisons are at each install boundary, not across normal game use.

[Implementation and regression details](../checks/2026-11-15-right-stick.md).
A temporary virtual joystick supplies Z/RZ and independent X/Y metadata; it is
not a physical controller. The owner explicitly deferred physical dual-stick
checks, so issue #55's hardware acceptance criterion remains open. These checks
do not establish full-game completion, audible output, Bluetooth disconnect,
exclusive ARM32/low-memory handset coverage or proportional analog game support.
