# AbyssME 0.1.0 Beta 1

This is the first public beta of AbyssME, a controller-first J2ME emulator for
Android gaming handhelds.

## Highlights

- Landscape library with Gallery, List, Grid, Recent, Favorites, and Folders
- Automatic compatibility preparation on first launch
- Per-game named controller profiles and in-game quick mapping
- Live View and virtual Screen controls during gameplay
- JAR, JAD, ZIP, and 7Z importing through Android's file picker
- Direct `ACTION_VIEW` launching from ES-DE, Beacon, and Android frontends
- Automatic icon/cover extraction with generated artwork fallbacks
- Symptom-based **Fix game** actions with optional expert settings

## Installation

Download `AbyssME-0.1.0-beta.1-fdroid-release.apk` below and install it on
Android 10 or newer. A physical controller and landscape display are strongly
recommended. This package can coexist with upstream J2ME Loader.

Automated unit tests, Android lint, debug assembly, and release assembly passed
for this build. The final beta still needs a fresh hardware pass on Odin 2;
controller focus and compatibility heuristics can vary between games.

## Known Limitations

- Phone model and screen-size selection is heuristic and may need **Fix game**
  for uncommon releases.
- There is no portrait launcher or on-screen virtual keypad.
- Some vendor-specific J2ME APIs remain limited by the upstream core.

Please report issues with the device model, Android version, game filename, and
visible symptom. Do not attach copyrighted commercial game files.
