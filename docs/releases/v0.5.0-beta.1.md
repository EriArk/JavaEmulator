# AbyssME 0.5.0 Beta 1

Java, Mophun and experimental Symbian/N-Gage in one adaptive Android app.

## Changes Since 0.4.0 Beta 3 Revision 1

- **xBRZ and CRT EasyMode:** two standalone image presets for Java and Mophun.
  xBRZ smooths pixel-art edges; CRT EasyMode adds a television-style image.
  Neither quietly adds FSR, interpolation or an LCD overlay.
- **Picture presets:** choose Pixel sharp, Smooth, Enhanced (FSR), or Custom.
  Try changes during play, then keep or undo them for that game.
- **Integer scaling:** enlarge Java/Mophun games by whole pixel multiples,
  without changing their original resolution. Uses Fit if 1x cannot fit.
  Mophun's LCD grid follows the same picture boundaries.
- **Experimental motion options:** optional frame interpolation and a separate
  100-300% Mophun CPU budget. Off/original defaults are preserved.
- **Screenshots:** Mophun can save the enhanced image or the original pixels.
  Custom library artwork keeps priority over automatically captured art.
- **Runtime fixes:** improve Java frame pacing, retain short GameCanvas button
  taps between polls, recover interrupted prepared imports, and remove stale
  Canvas controls when a game opens a native LCDUI screen.

Image options are under **Game menu > Display > Enhancements**. Integer scaling
is under **Display > Picture size**. Use **Try changes > Keep changes** to save.
Existing fast-forward, controller mapping, touch layouts and library transfer
remain available.

## Scope and Limits

Enhancements are experimental and opt-in. They do not guarantee 60 FPS or make
every game's artwork sharper. Java image effects require OpenGL ES without a
custom shader; the app does not replace one automatically. Symbian/N-Gage is
included but does not use these GPU effects. Frame interpolation can add latency
or visual artifacts; CPU budget can increase heat and affect busy-loop games.
Profiles imported with experimental settings explicitly enabled now apply them
in Release too. Choose Pixel sharp and disable interpolation to return to
ordinary presentation; Mophun CPU budget defaults to 100%.
