# AbyssME 0.7.0 Beta 6

## Shared profiles and extra touch buttons

- Set global touch/LCD defaults and create named profiles from **Settings →
  Profiles / Global defaults**. Link individual games or assign a profile to
  several prepared games. Edit a shared profile once; linked games use it on
  their next launch.
- Keep per-game exceptions, inspect which profile supplies each setting, and
  reset individual overrides. Existing game settings stay unchanged on upgrade;
  explicitly reset their touch/LCD overrides to adopt shared settings.
- Add up to twelve independent Gamepad buttons in **Edit touch layout → Extra**.
  Choose a key and label, size, opacity and separate portrait/landscape positions.
  Additional buttons are included in shared profiles.
- Library backups carry profile definitions and assignments. Phone backups carry
  portable per-game definitions. Restore preserves destination profiles when
  names or identities conflict.

## Downloads

| APK | Engines |
| --- | --- |
| `AbyssME-0.7.0-beta.6.apk` — ARM64, recommended when supported | Java ME, Mophun, experimental Symbian/N-Gage |
| `AbyssME-0.7.0-beta.6-armv7.apk` — requires 32-bit ARM Android support | Java ME and Mophun |

Both require **Android 10+** and use `io.github.eriark.abyssme`, version code
**320**. Install over the official app without uninstalling. These are alternate
architecture builds sharing one library. ARMv7 does not expose Symbian content;
returning to ARM64 makes it accessible again. Keep a backup before switching.
Games and firmware are not bundled.

ARMv7 remains a beta with limited hardware coverage. Retroid's native 32-bit
support does not establish performance on older, low-memory phones. Existing
N95 startup and experimental multiplayer limitations remain. This release does
not claim complete-game, human touch-comfort or fresh audible-output acceptance.
Matching app source, dependency/Symbian source bundles and SHA-256 checksums
accompany the APKs. GitHub Actions remains disabled.
