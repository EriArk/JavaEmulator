## Retroid verification

Device: Retroid Pocket Classic, Android 14, native ARM64 and ARM32 support.
The isolated package `io.github.eriark.abyssme.profilescheck.debug` was used for
instrumentation, keeping official app data separate. Its only build overlay
changes the Debug suffix; Release keeps the normal identity.

- **64 fresh ARMv7 Android checks pass** (16.603s): profile inheritance and
  overrides, migration, serialization, editor/draft cancellation, simultaneous
  extra-key input and release, bulk assignment UI and library backup restoration.
- **Two fresh ARMv7 target checks pass**: the process is 32-bit, required native
  libraries load, Symbian classes are absent, and hidden-platform preferences
  survive navigation. This is native execution, not ARM translation.
- The earlier **86 combined Debug checks** remain the dated
  [implementation evidence](../checks/2026-11-14-shared-profiles.md); they were
  not rerun and are not described as final signed-APK instrumentation.
- **Diamond Rush 1.1.6** passes the opt-in linked-profile/backup journey on
  ARMv7 (124.062s). Two added buttons are visible; GO opens the game/menu and
  starts a level. A shared opacity edit is resolved on reload while the explicit
  game size override survives. Four RMS files retain hashes through backup and
  restore; the relaunched game displays the checkpoint and the inherited 65%
  opacity. Captures were inspected. Zero-duration shell taps were too short for
  this polling game; 180ms injected presses worked. This is not a full-game run.
- On the **final signed ARM64 APK**, the actual UI creates a named profile,
  switches to Gamepad, adds/remaps/moves a button, and saves it. The serialized
  profile retains stable field names and the extra button after R8 optimization.
  A temporary assignment to **Asphalt 3 Street Rules 3D 1.1.5** loads this profile
  after a process restart; its extra 5 button operates the menu and starts a race.
  Driving is visible at 80 km/h after input.
- Switching to the **final signed ARMv7 APK** retains that profile and assignment.
  Asphalt again shows the extra button, accepts its input and starts a rendered
  race. A Debug-only Android deprecated-ABI warning was acknowledged before
  testing. ARM64 is recommended on devices that support it.

The Asphalt assignment was temporarily prepared in a backed-up config to isolate
runtime loading; UI bulk assignment is covered by the targeted tests. The
original game config was restored and the temporary named profile removed.

## Upgrade, cleanup and limits

The signed ARM64 APK upgrades Beta 5 (319) to Beta 6 (320) without uninstalling;
all **329 readable external files** have identical hashes immediately after the
update. The subsequent signed ARM64-to-ARMv7 switch preserves all **335 readable
files** present after the gameplay/profile check. Return to ARM64 preserves all **334 readable files** remaining after cleanup. Two pre-existing converted Mophun directories are
inaccessible to shell; these snapshots are not exhaustive backups of private
phone data. Retroid is left on the official ARM64 build. The two isolated
`profilescheck` test packages were removed after evidence collection.

No exclusively 32-bit/low-memory handset, sustained performance/thermal run,
complete game, human touch-comfort study, fresh audible-output acceptance or
live multiplayer-service check is claimed. Symbian/N-Gage engine behavior was
not freshly tested in a real game in this release; native packaging and the
earlier phone-backup tests remain the relevant evidence.

Local commands, build/test logs, mappings, inventories, signing/upgrade checks and
private game captures are retained under `build/releases/0.7.0-beta.6/`.
