# AbyssME 0.7.0 Beta 5

Two signed APKs now share the same version and application identity:

| Download | Use on | Included engines |
| --- | --- | --- |
| `AbyssME-0.7.0-beta.5.apk` | ARM64 Android devices; recommended when supported | Java ME, Mophun, experimental Symbian/N-Gage |
| `AbyssME-0.7.0-beta.5-armv7.apk` | Devices with 32-bit ARM Android support | Java ME and Mophun; no Symbian/N-Gage |

Both require **Android 10 or newer**. A 32-bit APK does not add support for
Android 7/8/9. Devices running a 64-bit-only Android system cannot install ARMv7.
About now identifies ARM64 or ARMv7 beside the version, making support reports
and download selection clearer. Both retain the Beta 4 compatibility-editor fix.

Install over the official app without uninstalling. These are alternate builds
of `io.github.eriark.abyssme`, version code **319**, not two separate libraries.
On devices supporting both ABIs, switching APKs retains stored data; Symbian
content is unavailable in ARMv7 and becomes accessible again with the combined
APK. Keep a backup before switching. Games and firmware are not bundled.

## Verification and limits

ARMv7 testing uses a native 32-bit process on a Retroid Pocket Classic with
Android 14. This is real ARM execution, but does not establish performance or
compatibility on older low-memory, exclusively 32-bit phones. Some newer Android
versions show a system warning for 32-bit apps; choose the normal ARM64 APK when
supported. ARMv7 remains a beta with limited device coverage.

Existing engine limitations remain, including N95 cold startup and experimental
multiplayer compatibility. No new full-game or audible/physical-controller
acceptance is claimed. See the [verification report](v0.7.0-beta.5-checks.md).
Matching app source, unchanged dependency/Symbian source bundles and SHA-256
checksums accompany both APKs. The Symbian source bundle is only needed for the
combined target. GitHub Actions remains disabled.
