# AbyssME 0.7.0 Beta 3

Prepared locally on November 10, 2026; publication is pending.

A library-transfer and interface update for Java, Mophun and experimental
Symbian/N-Gage. One adaptive ARM64 APK; Android 10 or newer.

## What changed

- Select and review several registered phones from an EKA2L1 folder or ZIP in
  one operation. Retain the transfer queue across interruptions, cancel safely,
  and retry unfinished copies/indexing without replacing newer imported saves.
- Make Java/Mophun import and backup recovery messages actionable in all eight
  supported languages, while retaining original filenames and technical details.
- Add Ocean and Amber appearance styles with light/dark variants. The appearance
  picker exposes its selected option to accessibility services.
- Add Website actions to Help/About and a copy-address fallback when an external
  browser cannot open a link.

## Install

The release candidate is **AbyssME-0.7.0-beta.3.apk**, version code **316**,
package `io.github.eriark.abyssme`. Install over the official app without
uninstalling it. Keep a backup of valuable saves. The separate legacy Phone app
still uses backup/restore migration. Games, firmware and accounts are not included.

The ARMv7 Java/Mophun target exists in source but is not a public APK in this
release; native 32-bit device acceptance remains outstanding.

## Verification and limits

The preceding local candidate checks include JVM/storage/UI regressions and
Retroid Pocket Classic checks of Deep Abyss resume, Diamond Rush RMS backup,
SimCity Townhouse restoration and the mixed-library DocumentsUI flow. These
are bounded scenarios, not complete-game compatibility claims. Release-specific
artifact, signature and update results are recorded in the
[verification report](v0.7.0-beta.3-checks.md).

Symbian/N-Gage remains experimental. N95/Asphalt 3 reaches moving gameplay and
survives LCD Soft/Classic Keep/Undo/Resume in a warm platform-hosted session,
but cold direct-card startup can remain blank even on Original. This release
does not claim a fix for that issue or arbitrary guest resolutions.

Java Bluetooth multiplayer remains experimental with low compatibility. Recent
paired-game checks do not establish sustained synchronization or different-network
matches. The Crash Bandicoot report still needs its exact edition identified.
The Discord action is deferred until a valid official destination is available.

App sources and matching dependency/Symbian sources are staged with the signed APK.
Existing third-party terms and notices remain unchanged. No private games,
firmware, signing material or device backups belong in the release assets.
