# 0.2.0-beta.1 Production Switch Checks

Date: 2026-10-13. Published at 19:04:52 UTC as a prerelease, tag `v0.2.0-beta.1`
at `5ced8fed4824f25783c1fb802ec0d348edb448f8`. All five GitHub asset SHA-256 digests
and sizes match local files. See the [checksum list](v0.2.0-beta.1/SHA256SUMS.txt).

## Implementation

- Ordinary builds use `engines/m3g`, including GLES geometry/rasterization,
  native fallback and the independent tone compiler. The 57-file generated
  source snapshot is checked against its pinned generator without timing hooks.
- Removed the old EPL M3G Java/native engine and tone implementation rather than
  relicensing them. Mascot Capsule remains independent and unchanged. Historical
  comparisons need a separate checkout at `05562126`.
- Promoted 9 selected Wolphun source files, 10 integration classes and fixture-
  free tests. Seven vendor files match upstream after line-ending normalization;
  Screen and Sdk retain the documented local changes. No private game executable,
  preview Activity, soundfont or signing secret is included.
- Added a keep rule for the manifest-discovered Mophun provider in optimized APKs.
- Fixed three generated-source indentation warnings with explicit return braces.
- A first source-set switch retained an obsolete Platform.class in incremental
  compiler output. Clean rebuilding removed it. `verifyProductionApks` now
  rejects old native/DEX descriptors, research hooks, game payloads and missing
  engine notices; this is an explicit denylist, not a general compliance scanner.

## Verification

- Ordinary Handheld/Phone debug and signed release APKs build. Both release
  lint tasks pass; existing warnings remain. JVM cases pass 14 per variant.
- Clean main release rebuild passes in 6m38s; the source-ZIP check independently
  builds both debug variants in 4m, without Git history or private signing files.
  The source-ZIP code matches the release tree; only release documentation differs
  between the tested `8de5e724` snapshot and the final archive tag. Final main APKs
  are installed on Retroid/Phone; Asphalt racing and RMS `Loaded: 4` are rechecked.
- Retroid Pocket Classic, Android 14: the normal production debug runtime passes
  363 renderer/tone checks, zero skips. Mophun fixture-free checks pass 25/25.
- Android 15 x86_64 Phone emulator: Mophun fixture-free checks pass 25/25.
  A full renderer run on SwiftShader was not repeated as a release claim.
- Both release APKs use version code 200 and the same signing certificate as
  historical beta.2. Certificate SHA-256:
  `722b6f8e74090bd3895eb0bc76433333c637e881758fc10ac276dd214499c38f`.
- Actual signed Phone upgrade: installed historical beta.2 in an empty release
  instance, imported the original RMS probe through DocumentsUI, saved 3, exited,
  and updated with `adb install -r`. The library entry remained. Its RMS file
  hash stayed `86a88d5b0c4b002bdb90f3254ef157b206932e244038cccf6a68b86356cbc401`
  before first launch. The new APK loaded 3, saved 4 and reopened with 4.
  This is a real signed-package upgrade, not a guarantee for every game's saves.
- Signed Mophun import through DocumentsUI and gameplay succeeds on Retroid and
  Phone. Retroid also imports Asphalt 3 3D 1.1.5 through DocumentsUI and reaches
  a moving race in the signed ordinary build. Phone touch OK progresses through
  Deep Abyss's menu/start screens to gameplay and life-loss handling. These are
  short ADB-driven checks, not a speed benchmark or complete playthrough;
  physical-button ergonomics, audio and whole-game completion are not inferred
  from ADB inputs or screenshots.
