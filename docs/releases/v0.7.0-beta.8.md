# AbyssME 0.7.0 Beta 8

Beta 8 fixes Lara's black/striped appearance and loading-screen text showing through her model in **Tomb Raider: Underworld 3D**. The cause was incorrect transparency when transferring M3G rendering to the Java ME screen.

Startup errors now show the original game exception instead of only `InvocationTargetException`.

- **ARM64:** `AbyssME-0.7.0-beta.8.apk` — Java ME, Mophun and the combined Symbian runtime.
- **ARMv7:** `AbyssME-0.7.0-beta.8-armv7.apk` — Java ME and Mophun, without Symbian.

Both require Android 10+ and update the existing app without uninstalling.

The reported **Crash Titans 1.3.7 Sony S700i JAR** was also checked. Its code and packed resources are inconsistent; the same reader fails on ordinary Java outside AbyssME. This release does not make that particular JAR playable.

Checks: 427 JVM tests per build, focused Retroid renderer tests, signed APK update and first-room checks. This is not complete-game acceptance. Source bundles and SHA-256 checksums are included.
