# Beta 3 Revision 1 Verification

Date: 2026-10-19. Candidate **0.4.0-beta.3-r1**, code **309**.
Preparation record; publication is recorded separately below when completed.
Earlier test artifacts/logs use the initial Beta 4 candidate name. The maintainer
requested updating the existing Beta 3 release instead; no Beta 4 is published.

## Scope

Shared session-only fast-forward, per-game settings and controller shortcut
arbitration. Trigger axes/digital events and multiple devices share one held
state. No game-name exceptions. Settings use the existing Try/Keep/Undo and
profile serialization. Select and navigation bindings are not offered as speed
shortcuts.

- Combined debug build passed. Fresh JVM run: 44 tests, including hold/toggle,
  custom baseline restoration, no guest-key leakage, trigger deduplication,
  multiple devices, frame caps, clock delays and invalid values.
- Retroid Pocket Classic, Android 14: 15 focused instrumentation checks passed.
  Includes shared shortcut UI/menu focus, profile persistence/Undo, converted
  Java clocks/sleeps/timers, MIDI/WAV progress through 400%, Mophun rate retention,
  native session input/focus callbacks and existing chrome behavior.
- Native suites executed on Retroid: capture cleanup/routing, card identity,
  file transfer, frame pacing, clocks and Speex audio. Audio tests cover eight
  rates through 400%, mono/stereo, bounds, EOF, reset and live transitions.
- Local logs: `build/beta4-debug-final.log`, `build/beta4-retroid-tests.log`,

## Limits

Injected controller events are not physical-button comfort acceptance. Automated
audio positions/waveforms are not a listening test. Requested speed is not a
guaranteed gameplay multiplier. No full-game/save acceptance or individual
Little Big City / Green Farm compatibility claim. Symbian/N-Gage remains
experimental, including pre-existing cold-relaunch limitations.
