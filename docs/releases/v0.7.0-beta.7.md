# AbyssME 0.7.0 Beta 7

## Separate graphics and control profiles

- **Settings → Graphics profiles** and **Settings → Control profiles** now have
  independent global defaults, named profiles and assignments. Each game can
  select one graphics profile and one control profile. Changing or resetting
  one category leaves the other intact; extra Gamepad buttons remain available.
- Graphics profiles include supported scaling, smoothing, built-in xBRZ/CRT,
  FSR/sharpness, interpolation, LCD filters and capture settings. Java GPU and
  Mophun support GPU effects; Symbian uses its supported host display options.
  Integer scaling falls back to Fit on Symbian. Java-only geometry options are
  identified in the editor's support information.
- Beta 6 combined profiles split automatically: LCD inheritance and exceptions
  move to graphics, while touch settings remain in controls. Other existing
  graphics remain explicit overrides. Reset the relevant category's overrides
  when you want existing games to inherit a shared setup.
- Both catalogs, including unassigned profiles, travel through library backups.
  Phone backups retain portable game definitions. Picture Keep/Undo preserves
  independent control drafts. Native geometry uses the normal Advanced / Try flow.

Renderer selection, external shader files, guest resolution, compatibility and
performance settings remain per game. Shared edits apply on the next game launch.
[Usage and engine limits](../SHARED_PROFILES.md).

## Downloads

| APK | Engines |
| --- | --- |
| `AbyssME-0.7.0-beta.7.apk` — ARM64, recommended when supported | Java ME, Mophun, experimental Symbian/N-Gage |
| `AbyssME-0.7.0-beta.7-armv7.apk` — requires 32-bit ARM Android support | Java ME and Mophun |

Both require **Android 10+**, use `io.github.eriark.abyssme` and version code
**321**. Install over the official app without uninstalling. Both architectures
share one library; Symbian content remains stored but unavailable under ARMv7.
Keep a backup before switching. Games and firmware are not bundled.

Matching app source, dependency/Symbian source bundles and SHA-256 checksums
accompany the APKs. Older/low-memory ARMv7 phones, complete games, fresh audible
audio and physical-button acceptance are outside this release's test scope.
Existing experimental engine/multiplayer limitations remain.
[Release verification](v0.7.0-beta.7-checks.md).
