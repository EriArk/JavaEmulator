# AbyssME 0.8.0 Beta 1

The ARM64 edition brings 24 platforms into one library. Open the platform gallery and choose a device to see its games. **Show platforms without games** reveals empty shelves. Select one to add games or install the system files it needs. You can also open the last library tab directly. Touch layouts and physical button mappings follow the selected device.

| Edition | Platforms |
| --- | --- |
| ARM64 | Java ME, Mophun, Symbian, N-Gage, WIPI / SKVM, Dingoo A320, Gemei A330, Aquaplus P/ECE, Watara Supervision, Mega Duck, Cybiko, Flash Lite, Gamate, Palm OS, Palm webOS, Firefox OS, KaiOS, Atari Portfolio, early iPhone OS, Arduboy / FX, Gamebuino Classic, Pokitto, original Thumby and ESPboy |
| ARMv7 | Java ME and Mophun |

Both APKs require Android 10 or newer. Install over the previous official version to keep your library. Supply your own games and any required firmware. Original Thumby takes a user-provided boot ROM and emulator UF2. Compatibility varies by game and system.

GP32, GameKing, Hartung Game Master, Epoch Game Pocket Computer, MediaTek MRE, Pocket PC, Gizmondo and Thumby Color remain in development while distribution questions are open. They have no tiles or engines in these APKs. [Upstream discussions](../checks/2026-11-22-license-remediation.md).

## Source and build materials

Extract the app source, then unpack the platform inputs ZIP at its root to restore the staged Android assets, SDL Java bridge and ARM64 native inputs. Each integration's directory under `engines/` contains its upstream revision, build steps and notices. The platform sources ZIP also includes CloudpilotEmu, touchHLE and its native dependencies, the GNU guest library sources, and LittleFS. The dependency and Symbian ZIPs supply the existing engine and Android dependency materials. The shared peer engine has its own source bundle.

Build the public ARM64 edition with `-PplatformRelease=true -PsymbianRelease=true -PsymbianSourceDir=/path/to/prepared/symbian`. Build the 32-bit edition separately with `-Parmv7=true`. Use `:app:assembleFdroidRelease :app:verifyProductionApks` and your own release key or the unsigned maintainer build option.
