# 0.6.0 Beta 1 Verification

2026-10-26. Candidate version `0.6.0-beta.1`, code 311. Release preparation in
progress; this file is not evidence of publication until the final artifact and
publication checks below are recorded.

## Scope

The cumulative #40 UI refresh and existing Fluxer/Java Bluetooth work are included.
The final slice styles common settings, brightness/style choices, account,
transfer and native system-file/archive surfaces. Existing import/backup,
credential storage and networking authority are retained. The sole enabled game
adapter is the existing Java Bluetooth path, now explicitly early experimental
with low compatibility in both Debug and Release.

No new engine, external-launcher implementation, firmware, game collection,
relay service or TrainerOS deployment is included. GitHub Actions stays disabled.

## Checks

- Combined Debug, instrumentation and signed Release built successfully with
  `-PsymbianRelease=true -PsymbianSourceDir=build/symbian-source-check`, without
  ABI injection or excluded native build tasks. Final build log:
  `build/v06-lifecycle-build.log`. This was an incremental build against the
  already restored pinned native tree, not a fresh clean-room native rebuild.
- Fresh execution of **391 JVM tests**, no failures/errors/skips. Release lint:
  **0 errors, 447 warnings**. Production guards pass for all engine payloads,
  the peer binary and component notices, and absence of old M3G/game/firmware
  payloads. Warnings are not claimed to be resolved.
- Final checks found and fixed a library shutdown race: Room reads and accepted
  asynchronous writes now share an owned queue; subscriptions and preference
  callbacks detach before queued connection closure. A dedicated check runs
  twelve close/write cycles and verifies persistence on each target. It passed
  on Retroid Pocket Classic / Android 14 and emulator / Android 35.
- Large-text checks found an outdated fallback card-height budget. It now
  reserves scaled title space; both fallback and resolved geometry are checked.
  Six focused cases passed at 480x320dp / 150% text on Retroid. Resolution and
  font scale were restored. `build/v06-retroid-compact-final.txt`.
- Final UI/lifecycle suite: **83 passed, 4 optional cases skipped** on Retroid
  (87 cases). Android 35 initially had 82 passes, 4 skips and one test-only
  asynchronous-list timing failure. Replace the helper's fixed 200ms sleep with
  a bounded wait for the actual adapter count; all **9 directory cases passed**
  on retry. The isolated failed case also passed before that helper change.
  Runtime code was unchanged by this test-helper correction. Logs:
  `build/v06-retroid-verified-ui.txt`, `build/v06-emulator-verified-ui.txt`,
  `build/v06-emulator-directory-final.txt`. Do not report the original emulator
  suite as an uninterrupted green run. The host-loaded emulator also required
  a cold restart after SystemUI stalls; no app data was wiped.

Prior scoped evidence remains in [the UI refresh record](../RETRO_LIBRARY_REFRESH.md)
and [Bluetooth game checks](../BLUETOOTH_GAME_SELECTION.md). It does not establish
different-network play, full games, universal compatibility or manual button comfort.
