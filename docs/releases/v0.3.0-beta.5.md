# AbyssME 0.3.0 Beta 5

Java, Mophun and experimental Symbian / N-Gage in one Android app.
Android 10+, arm64-v8a. Version code **304**.

## Downloads

- **[Handheld APK](https://github.com/EriArk/JavaEmulator/releases/download/v0.3.0-beta.5/AbyssME-0.3.0-beta.5-handheld.apk):** Landscape, controller-first,
  without an on-screen keypad.
- **[Phone APK](https://github.com/EriArk/JavaEmulator/releases/download/v0.3.0-beta.5/AbyssME-0.3.0-beta.5-phone.apk):** Portrait/landscape, with Phone and
  Gamepad touch layouts.

Install over the same variant to keep its library, settings and saves. Phone
and Handheld have separate data and can coexist. Games and firmware are not bundled.

## New Since Beta 4

- **Java startup:** fixed a circular wait that could prevent games from opening,
  reproduced with Age of Empires II Deluxe. The fix applies to the shared startup
  path, not only that title.
- **Phone controls:** a per-game Button theme can keep controls dark while the
  app uses its light theme. The number pad has clearer digits, letter legends
  and raised key faces. Both touch layouts use the selected theme.
- **More room for the game:** Phone's upper shortcuts open from a small edge arrow,
  overlay the picture and hide after five idle seconds. They no longer reserve a
  top row; normal game touches do not reveal the panel.
- **Live display changes:** fixed several shared buffer and rendering-lifecycle
  problems that could cause stale or missing pictures after changing screen size.
  Restart game remains available when a game cannot recover from a change.
- **Automatic screen setup:** recognize additional explicit screen dimensions
  and prefer original-resolution declarations over scaling hints. Existing
  saved settings are preserved.
- **Library transfer:** retain selected folders and pending access requests if
  Android recreates the app. Interrupted imports are not silently repeated.
- **Symbian sessions:** harden background pause and replacement-session callbacks.

## Known Limits

This is not a fix for every black screen or every incompatible game. Symbian /
N-Gage remains experimental, including unreliable native Asphalt cold relaunch.
Deluxe 02.00.35 reached Quick play on Android 14 Retroid and the Android 15 emulator;
Android 16, the reported 02.00.39 variant and complete campaigns are not verified.
No measured FPS improvement, universal game-speed correction or broad audio/save
compatibility is claimed.

Matching application and dependency source bundles and SHA-256 checksums accompany
the APKs. See the [release checks](https://github.com/EriArk/JavaEmulator/blob/main/docs/releases/v0.3.0-beta.5-checks.md)
for exact artifact/device verification and [fresh screenshots](https://github.com/EriArk/JavaEmulator/tree/main/screenshots/releases/v0.3.0-beta.5).
