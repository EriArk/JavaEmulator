# AbyssME 0.7.0 Beta 1 (Revision 1)

One Android APK for phones and handhelds: Java ME, Mophun and experimental
Symbian / N-Gage. Android 10 or newer, ARM64. Version code **314**.

## Revision 1

Game titles below artwork are now centered in Grid and Gallery. List keeps
start-aligned titles and metadata. Card sizes, artwork and line limits are
unchanged. This replaces the APK on the existing Beta 1 page; install the r1
APK over the previous version without uninstalling. Matching r1 app source uses
tag `v0.7.0-beta.1-r1`; the original source tag is preserved.
[Focused checks](v0.7.0-beta.1-r1-checks.md) and
[before/after captures](../../screenshots/releases/v0.7.0-beta.1-r1/README.md).

## What's Changed Since 0.6.0 Revision 1

- **Choose your app language:** English, Spanish, Brazilian Portuguese, Russian,
  French, German, Japanese or Simplified Chinese, plus System default. The choice
  is saved and works offline. Game language and user-created content are untouched.
- **More reliable Java audio:** fixes for volume, loading, seeking, replay,
  finite loops and callbacks. ADPCM retains 16-bit samples; direct MIDI players
  have independent output, gain and mute. This is not a new instrument bank.
- **Map the virtual gamepad per game:** select a drawn button and choose the
  phone key it sends. Use arrow/numpad templates or individual assignments,
  then Try/Keep/Undo. Physical-controller mapping stays separate.
- **Adjust Phone controls:** move or hide the menu handle and adjust button
  opacity. Preserve separate portrait/landscape layouts and existing profiles.
- **Clearer localized menus and setup:** improve long labels, large fonts,
  archive summaries, import/recovery messages and Social screens. Fix menu
  teardown during Activity recreation and preserve pending import information.
  Reconcile menu placement after rotation when Android delivers configuration
  and layout updates in different orders.
- **N-Gage 2.0 setup fix:** accept distinct partial updates that share a component
  UID, as used by the tested 1.40.1557 platform installer. Keep conflicting full
  packages blocked and identify the installer/component in the error message.

## Updating

Install `AbyssME-0.7.0-beta.1-r1.apk` over the official unified app. Do not uninstall
or clear app data. A library backup is recommended before any beta update.
The old separate Phone app still uses the
[menu-based transfer workflow](../LIBRARY_TRANSFER.md#moving-from-abyssme-phone).

`Game menu > Controls > Edit touch layout > Buttons` opens touch mapping.
`Settings > Language` changes the emulator UI, not game text.
For N-Gage 2.0, resume the pending import with the same supported platform
installer. Do not delete your virtual phone to work around the old UID error.

## Still Experimental

- Symbian/N-Gage compatibility varies by game and supplied phone system.
  The installer repair is not a promise that every N-Gage 2.0 game works.
- Java Bluetooth multiplayer remains early experimental with low compatibility;
  both players need matching game editions. No new multiplayer platform or
  relay fallback is added in this release.
- Some low-level diagnostics and inherited partial locales can still show English.
  Complete resource coverage is not independent native-speaker review.
- The exact reported quiet-music editions and Treasure Towers remain unverified.
  Audio repairs do not claim original-phone sound equivalence or universal fixes.
- Game files, firmware and proprietary platform installers are not included.
