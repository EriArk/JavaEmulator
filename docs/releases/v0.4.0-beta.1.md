# AbyssME 0.4.0 Beta 1

One APK for Android phones and gaming handhelds. Java, Mophun and experimental
Symbian / N-Gage are included. Android 10+, arm64-v8a; version code 306.
Games and firmware are not bundled.

## What Changed Since 0.3.0 Beta 6

- One adaptive app replaces separate Handheld and Phone downloads. Portrait and
  landscape, controller navigation and both touch layouts are available together.
- Per-game Control mode: Auto / Touch / Controller; On-screen buttons:
  Auto / Always / Off. Hiding controls returns their space to the game.
- Controller removal releases held buttons and pauses. Reconnection does not
  resume without a user action. Existing orientation and mappings are preserved.
- A compact Keep/Undo panel leaves more of the game visible during live previews.
- Java display changes preserve submitted frames, deliver size changes in order
  and recover correctly after backgrounding. GLES screenshot readback is fixed.
  This is not a claim that every black-screen case is solved.
- Audio follows emulation-speed changes where supported; pitch changes with
  tempo. Normal speed remains 100%, with frame-rate limiting independent.
- Mophun games can be imported from ZIP/7z archives. Folder discovery handles
  MPN, KJX and standalone JAD more consistently and reports incomplete scans.
- A Phone migration entry links existing backup/restore workflows.

## Install or Upgrade

Download **AbyssME-0.4.0-beta.1.apk**. It updates the former Handheld package
in place; do not uninstall first.

For the former Phone app, keep it installed and open **Settings > Library >
Library transfer** there to back up Java / Mophun. In the new app, choose
**Move from AbyssME Phone** and restore that ZIP. Review the selection; existing
games are not silently overwritten. Check your saves before removing the old app.
Symbian / N-Gage requires separate whole-phone backups. App-wide preferences
and external-launcher shortcuts are not transferred.

"One APK" refers to phone/handheld UI, not every CPU architecture: this combined
build is arm64 only. No account or system-file download service is required;
you supply your games and any required phone firmware.

## Checks and Limits

Signed upgrade and menu-driven Phone migration were checked on Retroid Pocket
Classic (Android 14). Two migrated RMS files matched their source hashes;
existing game files and saves were retained. Shared controller, touch, settings
and import regressions ran on Retroid and an Android 15 emulator during preparation.
See the [verification record](v0.4.0-beta.1-checks.md) for exact boundaries.

Symbian compatibility is experimental; native Asphalt cold relaunch remains
unreliable. Physical unplug/replug, Android 16, listening quality and complete
campaigns are not certified. Java pause uses the existing MIDlet lifecycle,
not forced suspension of arbitrary game threads.

## Source and Integrity

The release includes the signed APK, matching application source, dependency
sources, pinned Symbian sources and SHA256SUMS.txt. Component notices are retained;
the combined application is GPL-3.0-only. GitHub Actions remains disabled.
