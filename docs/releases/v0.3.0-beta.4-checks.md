Date: 2026-10-17. Version code **303**, Android 10+, arm64-v8a.

- Clean combined signed build with `-PsymbianRelease=true` and
  `-PsymbianSourceDir=build/symbian-source-check`, using the pinned restored tree.
- Both release APKs, `verifyProductionApks`, both release JVM suites and both
  lint tasks passed. JVM: **29 tests per variant**, zero failures/errors.
  Lint: zero errors, **403 Handheld / 410 Phone warnings** remain.
- APK guards verified engines/notices and absence of private game packages,
  phone dumps, original sound banks and the removed legacy renderer/tone code.

  `722b6f8e74090bd3895eb0bc76433333c637e881758fc10ac276dd214499c38f`.
- APK metadata reports code 303, `0.3.0-beta.4` / `0.3.0-beta.4-phone`, SDK 29
  minimum and arm64-v8a. Local log: `build/beta4-release-build.log`.

## Final Signed APKs on Retroid

Retroid Pocket Classic, Android 14; Handheld 1240x1080, Phone portrait 1080x1240.
Input was injected through ADB, not human controller or audio-listening acceptance.

- Both signed variants installed successfully with `adb install -r`.
  Handheld upgraded beta.3 without losing its 39-entry library.
- Gallery Automatic/Portrait and Wide, List and Grid were opened and captured.
  Automatic uses the portrait card format on this near-square handheld.
- Gravity Defied reached its First Life track. The shared menu, graphical
  mapper and restart confirmation were inspected. Confirmed restart replaced
  the Java process (PID 21044 -> 21290) and returned to the game's main menu.
- Phone retained its two library entries and hidden Display/Screenshot
  shortcuts. G.R.A.W. 2 reached its main menu using touch input. Portrait
  orientation and both Phone/Gamepad decks applied through Try changes / Keep.
- After captures, the temporary Phone installation was removed with `-k`,
  retaining its data. Only production Handheld code 303 remains installed.
  The library was reopened and still reports **39 games**.

The preceding [development checks](../checks/2026-10-17-gallery-restart.md)
cover emulator layout matrices and Bounce Tales, Deep Abyss and Snakes restart
on physical Retroid. Native game restart and that emulator matrix were not
repeated on these final signed APKs; do not present them as final-release runs.

## Sources and Limits

The fresh 118-artifact Android dependency inventory matches beta.3, including
artifact hashes. Dependency source preparation completed, and all 49 native
source archive hashes matched the lock. Unchanged dependency/native source
bundles are reused; the app source archive is exported from the new release tag.
The previously restored native source tree was reused, not restored a second time.

Fresh, unretouched [screenshots](../../screenshots/releases/v0.3.0-beta.4/) come
from these signed APKs. Older promotional sets were removed from the current
tree; historical documentation links pin their original files to commit 23da5d4b.

Restart is a recovery action, not a general black-screen fix. RG Cube hardware,
ES-DE, Samsung Android 16, full games, audio/save round trips and human touch/
controller acceptance remain unverified. Native Asphalt cold relaunch and broader
Symbian compatibility remain open. Games and firmware are not distributed.
