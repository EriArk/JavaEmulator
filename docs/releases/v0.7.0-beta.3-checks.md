**Published 2026-11-10 at 21:20:07 UTC.** Version `0.7.0-beta.3`, code **316**. Source and the runtime tag are pushed. All five
release asset names, sizes and GitHub SHA-256 digests match staging;
authenticated draft and unauthenticated public APK/checksum downloads match.
[GitHub prerelease](https://github.com/EriArk/JavaEmulator/releases/tag/v0.7.0-beta.3).

`-PsymbianRelease=true -PunsignedRelease=true -PnativeBuildJobs=2`.
**424 JVM tests passed**, zero failures/errors/skips. Release lint reports zero
errors/fatal issues and **806 warnings**; this is not a warning-free result.

All 118 freshly resolved runtime artifact hashes match the reused dependency
bundle. Its 116 referenced source/upstream files pass hash verification. Native

Beta 1 filenames and bytes. Restoration is distinct from the incremental build.

## Executed upgrades

**Retroid Pocket Classic, Android 14, native ARM64:** the official package was
Beta 1 Revision 1 (314), not Beta 2. `adb install -r` upgraded it successfully to
316 without uninstalling. The separate Debug/test packages were not replaced.
All 329 directly readable external files retained their hashes immediately after
installation. Two converted Mophun directories are inaccessible to shell; this
limited snapshot does not stand in for the in-app backup checks below.

Before installation, the app exported 36 Java/Mophun games plus their saves and
settings, and both RH-29 / N95 phones. The Java/Mophun backup has 296 verified
payload hashes; the phone backups contain 1,264 / 6,535 verified file hashes.
An initial shell tar attempt was unusable due to access errors and is not counted
as a successful backup. The readable files were also individually copied and
verified. All backups are private local evidence, excluded from publication.

After installation and library startup, a new Java/Mophun export contains the
same 36 game records (including favorites/play history) and all 296 identical
payload hashes. The Classic appearance, system language/brightness selection and
remembered Symbian grid remain visible. Both phones remain registered. Fresh
post-upgrade phone exports preserve the full RH-29 and N95 payloads byte for
byte (1,264 and 6,535 files), with identical phone identity and file manifests;
only the backup creation metadata differs.

**API 30 emulator, ARM64 translation:** installed the official Beta 2 APK (315),
then restored a private two-game fixture through DocumentsUI before upgrading.
The final signed APK installs with `-r`, retaining UID 10169 and both catalogue
entries. A post-upgrade read confirms six save files and two game payloads match
the original fixture. Original Java configuration values remain; 21 default
fields were added during import/normalization. Mophun configuration was already
reported as not transferred by Beta 2's importer. The initial shell snapshots
were denied by Android storage protection and contain zero files; their empty
comparison is explicitly not preservation evidence. Emulator-only root access
was used for the subsequent read, never on the physical Retroid.

## Final signed gameplay smoke

On the physical Retroid, launch the existing DeepAbyss14 library entry, select
Resume and reach the animated level. Brief directional input reaches the guest's
"Life lost" screen; the host game menu and exit confirmation remain responsive.
Leave without saving and return to the library. Inputs were injected through
ADB, including held gamepad events: instantaneous down/up events initially did
not advance the guest menu. This short optimized-APK smoke is not a new test of
physical buttons, audible sound, or full-game progress. Preservation comparisons
above were completed before this smoke; its backups remain available privately.
