# AbyssME 0.6.0 Beta 1

One Android APK for phones and handhelds: Java ME, Mophun and experimental
Symbian / N-Gage. Android 10+, arm64. Games and phone system files are not included.

## A More Consistent Interface

- Four platform tabs, with Gallery, Grid and List retained. No permanent game
  details sidebar. Each platform remembers its view, filters and position.
- Softer molded controls and recessed content surfaces in light and dark themes.
  Shared side panels on handhelds and bottom panels on phones keep actions nearby.
- Game menus group Display, Controls and Social without removing Restart,
  Screenshot, Fast-forward or advanced options. Supported picture previews apply
  immediately; Keep saves, Undo/Back abandons unconfirmed changes.
- Phone keypad Separate/Overlay modes retain independent orientation layouts.
  Physical controller mappings and the Gamepad/Legacy alternatives remain intact.
- Account, settings, library transfer, system-file setup and archive review now
  share the same visual language. Short screens and large text get compact layouts.
- Fix a library shutdown race found during final checks: finish queued database
  work before closing its connection, without dropping accepted library writes.

## Early Experimental Multiplayer

**Low compatibility. Expect failed connections, unsupported games and bugs.**

Social provides Fluxer sign-in, friends, direct chats and AbyssME-only public
lobbies. Rooms support admission, local game preparation, explicit Ready, launch
and return. Existing TrainerOS listings remain separate.

The first game adapter is **two-player Java Bluetooth** over an encrypted direct
network connection. Both players need the **same game edition/file**. Not every
Bluetooth game works, and some networks cannot establish a direct connection.
Fluxer carries signaling, not gameplay data. There is no universal relay fallback.
Mophun/Symbian multiplayer and TrainerOS cross-play are not supported.

Open a compatible Java game's actions and choose **Play Together**, or open
**Social > Lobbies**. Sign in through the official Fluxer website, select matching
games, then use Ready. The original game's Bluetooth host/join menus may still
be necessary. Single-player remains available without an account.

## Updating

Install over the official unified AbyssME app; do not uninstall first. Back up
valuable progress through Settings > Library > Library transfer. Symbian/N-Gage
uses separate whole-phone backups. The former Phone app remains a separate
migration source; never remove it before confirming transferred games and saves.

## Scope and Next Phase

This is a prerelease, not a compatibility guarantee. Native Asphalt cold relaunch,
some Java startup/speed cases and broader online compatibility remain open.
Existing experimental graphics effects remain opt-in; there is no universal
60 FPS promise. Native size/rotation changes still apply on resume, not as Java
GPU previews.

After 0.6, the planned focus is **polish, reliability and game compatibility**,
rather than expanding the feature list. Test reports on ordinary play, controls,
imports, saves and online failures will guide that work.
