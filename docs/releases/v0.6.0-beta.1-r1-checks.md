## Change and Checks

`MenuPlacement` shares a dp-based policy across `GameMenuDialog` callers.
Explicit confirmation pages always center. Ordinary panels need an aspect ratio
of at least 1.4 and 240dp remaining beside their nominal width before using a
side position. Otherwise they center, except tall touch phones which retain
bottom sheets. A controller alone no longer forces right alignment.

Confirmation call sites include game Exit/Restart, library deletion/art reset,
account/contact/room actions, import review and native game uninstall. This is
not a rewrite of every inherited Android dialog. Page cleanup and transitions
stay in the existing dialog, retaining preview cancellation, focus and Back.

- Combined Debug, instrumentation, signed Release, release lint and production
  APK guards passed. Command: `:app:testFdroidDebugUnitTest --rerun
  :app:assembleFdroidDebug :app:assembleFdroidDebugAndroidTest
  :app:assembleFdroidRelease :app:lintFdroidRelease :app:verifyProductionApks`
  with `-PsymbianRelease=true -PsymbianSourceDir=build/symbian-source-check
  --offline --console=plain`. Log: `build/v06-r1-build.log`.
  Incremental build against the previously restored pinned native tree, not a
  fresh native clean-room rebuild.
- **395 JVM tests**, no failures/errors/skips. Matrix includes portrait, square,
  near-square, compact and wide dimensions with both input modes and previews.
- Release lint: **0 errors, 447 warnings**. Existing warnings are not resolved
  by this patch. Production guards pass; no engines or dependencies changed.
- Retroid Pocket Classic / Android 14: **34 Android cases passed, 7 optional
  authenticated-room cases skipped** (41 total). The updated helper and full
  focused suite passed again in 59.72s. Log: `build/v06-r1-retroid-retest.txt`.
- Android 35 emulator: initial 41-case run had one focus assertion failure.
  The test checked focus after a fixed 150ms before the window acquired focus.
  Replace that test-only delay with bounded layout/window-focus readiness,
  retaining the first-action assertion. Full retry: 41 cases, no failures,
  with the same seven optional room cases not exercised (128.336s).
  Logs: `build/v06-r1-emulator-tests.txt`, `build/v06-r1-emulator-retest.txt`.
  Do not describe the initial emulator pass as uninterrupted green.
- Instrumentation covers actual centered window coordinates, confirmation Back
  without dismissal, exactly-once preview cleanup, adaptive placement after
  rotation, controller focus, preview and existing common-page journeys.
  No fresh real-network multiplayer acceptance is claimed.
