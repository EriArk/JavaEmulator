## Fix and targeted verification

The reported library Advanced panel sent Android's `android.intent.action.EDIT`,
but ConfigActivity recognized only its internal `config.edit` action and entered
the launch flow. Both edit actions now open the editor. A second entry through
GameSettingsActivity inherited the first-preparation launch action; it now sets
an explicit edit action. Normal launch and Try in game code are unchanged.

`CompatibilityNavigationTest` passes on the API 30 emulator (2 tests, 19.936s).
It exercises GameSettingsActivity with default, internal edit and absent incoming
actions, plus the standard Android edit action used by the library card. Each
case reaches the actual configuration UI and records zero MicroActivity launches.
Synthetic fixtures are removed afterward. This is navigation evidence, not game
compatibility or physical-device acceptance.

succeeded from the intermediate local code 317 to final code 318. Earlier in

shows Fix game, Expert settings and Screen options instead of starting the game.

returned no root on this device, so this check used screenshot inspection.
