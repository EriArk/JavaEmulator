# AbyssME 0.3.0 Beta 1

Java, Mophun and experimental Symbian / N-Gage in the same Android library.

## Downloads

- **Handheld:** landscape, physical-controller focused.
- **Phone:** portrait/landscape, numeric keypad or virtual Gamepad.
- Android 10+ and **64-bit ARM (arm64-v8a)** are required for these combined APKs.
  The previous 0.2 beta remains available for other supported architectures.
- Updates retain the existing Java/Mophun library. The variants have separate
  data. Private Symbian test packages are separate installations, not upgrades
  of these production packages; use Phone backups to transfer their phone data.
- No games or phone firmware are included.

## New

- One in-game menu for Java, Mophun and Symbian: Resume, Display, Controls,
  Screenshot, More and Exit game. Screenshot is available for Java Canvas games,
  not LCDUI forms. Screenshot-button visibility is under More.
- Exit confirmation stays paused in the same menu. Resume has first controller
  focus, including while a settings trial is active. Existing Try/Keep/Undo,
  held-Select mapping and engine-specific settings remain available.
- Embedded Symbian / original N-Gage / N-Gage 2.0 import and launch. Installed
  native games join Gallery/List/Grid, search, Favorites and Recent.
- System files can be added before games. Setup explains which phone dump or
  installer is needed and resumes retained imports after requirements are added.
- SIS/SISX and native game ZIP/RAR/7z import, batch selection, reusable component
  installers, per-file results and recoverable queues. A phone choice can be
  reused for the same package type in one archive.
- Symbian display rotation/scaling, per-game controller mapping, Phone numeric
  and Gamepad decks, direct guest touch and screenshots.
- Menu-based whole-phone backup/restore for Symbian games, saves and controls.
  Java/Mophun continue to use Library transfer.

## Getting Started With Symbian

Open **System files** from the library/settings menu and add a compatible
EKA2L1 phone dump: a prepared ZIP/7z, or ROM with its matching RPKG when required.
Then use the library **+** to add the game. N-Gage 2.0 games also require their
platform installer; setup requests it separately and reuses the saved copy.
Use only files you have the right to use.

## Known Limits

Symbian support is experimental. Snakes has reached gameplay on Retroid;
Asphalt 3 has reached a race but cold relaunch remains unreliable. These are
not complete-game, audio-listening or save/relaunch compatibility guarantees.
Legacy/conditional SIS dependencies, universal mixed-platform archives and native
external-launcher integration remain incomplete. One retained import queue is
supported; game archives have a 1 GB limit. Encrypted/multipart archives are
not supported. A native installation interrupted mid-write requires explicit
retry, not an automatic rollback claim.

Java/Mophun functionality from 0.2 remains. GeneralUser GS supplies Symbian MIDI
instruments, so their timbre need not match a particular old phone.
