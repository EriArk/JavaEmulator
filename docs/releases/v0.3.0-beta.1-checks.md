[v0.3.0-beta.1](https://github.com/EriArk/JavaEmulator/releases/tag/v0.3.0-beta.1).

## Implementation

- Shared `GameMenuPages` supplies the home page and paused exit confirmation
  to Java, Mophun and Symbian. Hosts retain engine lifecycle ownership.
- Resume is the first focus target; Display, Controls, Screenshot, More and
  Exit game use consistent navigation. Java LCDUI forms omit Screenshot.
- Fullscreen game dialogs set their window flags before attachment on both
  variants, preserving hidden system bars without a transient host resize.
- The accumulated Symbian setup, archive queue, component guidance, shared
  library, touch/display/mapping and phone backup work is included. Earlier
  dated checks are retained in `docs/SYMBIAN_INTEGRATION.md`.

## Limits

Snakes gameplay/native screenshot checks and Java/Mophun menu checks are bounded
smoke tests, not broad compatibility or complete-game approval. Asphalt 3 native
cold relaunch remains unreliable. Legacy/conditional SIS dependencies, universal
mixed-platform collections and native external-launcher integration remain open.
Game/firmware inputs and full private diagnostics are not published. Local log
paths above are maintainer evidence, not downloadable release assets.

GitHub Actions remains disabled. Source publication, signed APK checks and
public release availability are separate steps.
