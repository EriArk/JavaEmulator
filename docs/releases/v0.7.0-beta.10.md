# AbyssME 0.7.0 Beta 10

Beta 10 adds **global physical-controller profiles** and improves Mophun sound and game speed.

Open **Settings → Physical controller profiles** to edit the global mapping or create reusable profiles for buttons and both sticks. Assign them to games from the manager or each game's Controls page. Graphics, touch layouts and physical mappings stay independent. Existing per-game overrides take priority; shared changes apply the next time the game opens. Profiles are included in library backups.

Mophun sound is now enabled for every game. Short BEEP effects and `vBeep` are supported, and PCM follows pause and emulation speed. A common phone-model execution budget reduces excessive speed in CPU-dependent games such as the supplied Boulder Dash and Lemtris versions.

- **ARM64:** `AbyssME-0.7.0-beta.10.apk` — Java ME, Mophun and experimental Symbian/N-Gage.
- **ARMv7:** `AbyssME-0.7.0-beta.10-armv7.apk` — Java ME and Mophun, without Symbian.

Android 10+ is required. Both update the existing app in place. Back up important saves before updating or switching architecture. Source bundles and SHA-256 checksums are included.

Boulder Dash 1.1 and Lemtris 1.0 for T610 reach gameplay/tutorial with recorded audio in bounded Retroid checks. The older cracked T300 Boulder file remains unconfirmed beyond level selection; V-Rally 2 and 1849 Gold Rush were unavailable for testing. Phone timing is approximate, and physical dual-stick testing remains pending. Fixes are enabled globally, without a game allowlist.
