# AbyssME 0.3.0 Beta 4

Java, Mophun and experimental Symbian / N-Gage in one Android app.
Android 10+, arm64-v8a. Version code **303**.

## Downloads

- **Handheld:** [AbyssME-0.3.0-beta.4-handheld.apk](https://github.com/EriArk/JavaEmulator/releases/download/v0.3.0-beta.4/AbyssME-0.3.0-beta.4-handheld.apk). Landscape, physical-controller-first, without an on-screen keypad.
- **Phone:** [AbyssME-0.3.0-beta.4-phone.apk](https://github.com/EriArk/JavaEmulator/releases/download/v0.3.0-beta.4/AbyssME-0.3.0-beta.4-phone.apk). Portrait/landscape with Phone or Gamepad touch controls.

Install over the same variant to retain its library and settings. The variants
have separate data and can coexist. Games and phone firmware are not included.

## New Since Beta 3

- **Gallery cover formats:** Library menu now offers Automatic, Wide and Portrait.
  Covers fit without cropping or stretching, including wide banners. Your choice
  is saved; existing image files are unchanged. List and Grid still show icons.
- **Square-screen library:** a compact header and responsive card sizes leave
  more room for games on square and near-square handhelds. The side detail pane
  no longer squeezes these layouts. This does not stretch the game screen to 1:1.
- **Restart game:** restart directly from the normal in-game menu in all three
  engines. The confirmation uses saved settings and discards unconfirmed previews.
  Unsaved progress can be lost. A stale Symbian menu callback that could pause
  the replacement session has also been fixed.

## Known Limits

Restart is a recovery shortcut, not a general fix for black screens after display
changes. Symbian / N-Gage remains experimental, and compatibility varies by game
and supplied phone files. Broad audio/save-roundtrip compatibility and real RG
Cube acceptance have not been established. Earlier limitations, including native
Asphalt cold relaunch, still apply.
