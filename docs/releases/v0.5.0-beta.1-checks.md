## Limits

Effects remain opt-in and experimental. There is no universal 60 FPS, guaranteed
visual improvement, proportional CPU-budget speedup, physical-button comfort,
full-game save or listening-test claim. Interpolation can add latency/artifacts;
budget increases can affect busy-loop games and power consumption. Symbian does
not gain these image effects; its existing compatibility limits remain.

GitHub Actions remains disabled. GitHub publication is separate from website or
Nextcloud deployment; neither server is changed in this checkpoint.
