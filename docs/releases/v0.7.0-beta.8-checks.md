Linux container. Each freshly passes **427 JVM tests**, with no failures, errors
or skips, and production APK guards. Lint reports zero errors, with 810 ARM64 /
1,303 ARMv7 warnings. GitHub Actions remains disabled; no clean-room native
rebuild or server round trip was repeated.

Manifests confirm code 322 / 0.7.0-beta.8, minSdk29, targetSdk34, official app ID
and non-debuggable builds. ARM64 contains 18 native libraries; ARMv7 contains 16
ARM32 libraries and no Symbian runtime. ELF class, alignment and signatures pass;
unsigned payload entries remain identical after signing. Certificate SHA-256:
`722b6f8e74090bd3895eb0bc76433333c637e881758fc10ac276dd214499c38f`.
Signing keys stayed outside the builder and uploads.

All 118 runtime artifact hashes per target match the dependency bundle. Its 117
source references resolve to 112 distinct files, freshly rehashed. Dependency
and Symbian source bundles are unchanged; matching tracked application/runtime
sources are in the app-source Git archive. Native-source restoration was not
repeated; see the [Beta 5 scope](v0.7.0-beta.5-checks.md). Game files, credentials
and private captures are excluded from publication.

## Retroid checks

Device: Retroid Pocket Classic, Android 14, supporting ARM64 and native ARM32.

- **88 renderer tests pass on each architecture**, including the new MIDP target
  opacity regression, clipping, subsequent 2D drawing, fragment-alpha blending,
  RGBA Image2D preservation, GPU transfer/texture/scene/batch and release checks.
  Separate Debug instrumentation builds were used. An additional ARMv7 process
  check confirms 32-bit execution and loading required native libraries without
  Symbian. An initial ABI-test invocation omitted its opt-in argument and skipped
  two tests; only the subsequent explicitly enabled process check is counted.
- Final signed ARM64 and ARMv7 APKs each display Lara correctly in the supplied
  Underworld 1.7.1 first Adventure room and while moving/turning toward the door.
  Official Beta 7 reproduces the black/striped model and stale loading text.
- Both signed builds show the original bounds exception for supplied Crash Titans
  1.3.7. The unchanged game reader reproduces the same failure on host Java,
  independently of AbyssME. That inconsistent JAR remains unplayable.
- Signed Beta 7 to ARM64 Beta 8 upgrade, switch to ARMv7 and return to ARM64 each
  preserve hashes of all **357 readable external library files** at their install
  boundary. This is not a claim that normal gameplay leaves saves/cache unchanged.

Retroid is returned to signed ARM64. Temporary instrumentation packages are
removed. No user library reset or game removal was performed.
[Diagnosis and supplied-file hashes](../checks/2026-11-15-tomb-underworld.md).
