# AbyssME 0.3.0 Beta 2

A maintenance beta for the shared Java, Mophun and experimental Symbian / N-Gage library.

## Downloads

- **Handheld:** landscape, physical-controller focused.
- **Phone:** portrait and landscape, numeric keypad or virtual Gamepad.
- Both APKs require **Android 10+ and 64-bit ARM**. Install over the matching
  previous release to retain its data; the variants have independent libraries.
- Games and phone firmware are not included.

## Changes Since Beta 1

- Added Light, Dark and Follow system appearance across the library, settings,
  installer, game menus and Phone controls. Improved the mapper on narrow screens.
- Phone users can hide Display and Screenshot shortcuts independently under
  **More > On-screen shortcuts** or **Settings > Playing**. Menu remains available.
- Restored tactile feedback for the numeric and Gamepad touch layouts across all
  three engines. **Controls > Tactile feedback** supports Try / Keep / Undo.
  Android's touch-feedback setting is respected; this does not add controller rumble.
- Improved Java screen startup, screen changes and pause/resume through shared
  lifecycle handling. This is not a guarantee that every previously blank game works.
- Automatic Java setup now uses explicit size and phone hints in original JAR
  filenames, below declared game metadata. Existing/manual profiles are preserved.
- Added per-game FPS presets in More and Display, with persistent Try / Keep / Undo
  and steadier frame pacing. This is a frame limit, not a universal speed fix.
- Identical Java imports from another location offer reuse of an installed game
  or a separate copy. Confirmed reuse preserves saves/settings and is remembered.
- Improved returning to external launchers after cancellation and errors. Installed
  native games can export an `.abyssme` launch file. See [launcher setup](https://github.com/EriArk/JavaEmulator/blob/main/docs/LAUNCHER_INTEGRATION.md).
- System-file import accepts ZIP/7z archives containing a ROM and matching RPKG.
  Import errors remain visible, with guidance about missing requirements.
- Supported SIS/SISX games can be uninstalled from their exact virtual phone,
  with backup access, dependency checks and verification before library removal.
  Protected/shared packages and unsupported ownership cases are blocked.
- Game information now shows the installed Java game's version and vendor.

## Known Limits

Symbian / N-Gage remains experimental. Snakes has reached gameplay; native
Asphalt 3 cold relaunch remains unreliable. Card-only and N-Gage 2.0 game removal
are not supported by the SIS uninstaller. Legacy dependencies and broad mixed-
platform collections still need work. System files must be supplied separately.

Beacon, Pegasus and Daijisho were exercised on Retroid during development;
**ES-DE has not been verified**. Intermittent game-startup reports, physical
controller ergonomics and perceived haptics on other phones remain open.
Passing instrumentation is not full-game, audio-listening or human acceptance.
