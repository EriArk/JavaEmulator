# AbyssME 0.6.0 Beta 1 - Revision 1

This updates the existing Beta 1 release, not a new beta series. Use
**AbyssME-0.6.0-beta.1-r1.apk**, version code **312**, for phones and handhelds.
Android 10+, arm64. Install over the official app; do not uninstall first.
Games and phone firmware are not included.

## Revision 1

- Short confirmations, including Exit and Restart, open in the center.
- Ordinary panels are centered on square and near-square handheld displays.
  Wide screens retain side panels only when useful space remains alongside them.
- Portrait phones retain bottom panels for ordinary game settings; confirmations
  are centered there too. Preview, Back, controller focus and pause behavior are
  retained. There is no extra placement setting to configure.
- Add a dark-theme screenshot collection: the library in Gallery/List/Grid,
  touch keypad and gamepad, controller mapping, settings, transfer, Java gameplay
  and native N-Gage gameplay. Captions distinguish signed Retroid captures,
  simulated handheld viewport sizes and phone-emulator Debug captures.

## Included in 0.6

Four platform tabs, contextual game actions, Soft Console surfaces and reversible
picture presets share one adaptive interface. Java, Mophun and experimental
Symbian/N-Gage remain in one APK. Existing light-theme support remains available;
the new press screenshots intentionally show only the dark theme.

Multiplayer remains **early experimental, low compatibility**. Fluxer sign-in,
friends, chats and AbyssME-only lobbies support the existing two-player Java
Bluetooth adapter. Both players need the same game edition. Some games and
networks cannot connect; there is no relay fallback or Mophun/Symbian online
adapter. Offline play does not require an account. No networking or engine
compatibility change is claimed for this revision.

Back up important progress through Settings > Library > Library transfer.
Symbian/N-Gage uses whole-phone backups. The separate old Phone app remains a
migration source; retain it until transferred games and saves have been checked.
