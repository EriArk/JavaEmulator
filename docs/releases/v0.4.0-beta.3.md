# AbyssME 0.4.0 Beta 3

One adaptive APK for phones and handhelds, version code 308. Games and firmware
are not included. See the verification record for publication status and checks.

[Download APK](https://github.com/EriArk/JavaEmulator/releases/download/v0.4.0-beta.3/AbyssME-0.4.0-beta.3.apk).
The three ZIP files contain source code, not additional installation packages.

## Library

- Combine All games, Recent or Favorites with a platform filter: Java ME,
  Mophun, Symbian or N-Gage. The library remembers the selected collection and
  scroll position.
- Play last starts the most recently played game across platforms. It does not
  restore a running session or create a save state.
- Edit card groups title and artwork actions. Favorites are also directly
  available from touch game options.
- Custom Symbian/N-Gage titles survive rescans and now travel with whole-phone
  backups, including edits made after restoring a copy.

## Picture and Screenshots

- Optional LCD Soft and LCD Classic effects for Java Canvas, Mophun and
  Symbian/N-Gage, with adjustable intensity and live Try / Keep / Undo.
- The grid follows guest pixels and image rotation, not the touch controls or
  unused screen area. Correct fractional-scale grid alignment and use logical
  Mophun pixels with HD rendering.
- Choose Clean or With LCD effect for in-game screenshot exports. Exports omit
  emulator controls and respect picture rotation. Processing is size-bounded.
- Effects remain Off and screenshot export remains Clean by default.

## Compatibility and Transfer

One adaptive APK for Android 10+ ARM64 phones and handhelds. Java, Mophun and
experimental Symbian/N-Gage remain included; games and firmware are not bundled.
The old separate Phone app still needs the existing in-app transfer workflow.

New Symbian phone backups use format 3. Update the receiving app before importing
one; Beta 2 cannot read it. Existing format-1 and format-2 backups remain supported.
Restoration creates an independent phone and does not replace existing saves.
Favorites, play history and Android library row IDs are not part of these backups.

This is not a new game-compatibility or performance guarantee. Symbian/N-Gage
remains experimental, including the known Asphalt 3 cold-relaunch issue.
