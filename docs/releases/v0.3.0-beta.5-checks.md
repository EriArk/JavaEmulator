Date: 2026-10-18. Version code **304**, Android 10+, arm64-v8a.

- Clean signed combined build using `-PsymbianRelease=true` and the previously
  restored pinned tree at `build/symbian-source-check`. Both release APKs,
  `verifyProductionApks`, both lint tasks and both JVM suites passed.
- JVM: **29 tests per variant**, zero failures/errors. Lint: zero errors;
  **404 Handheld / 411 Phone warnings** remain.
- Production guards verified engine/notices presence and absence of private
  game packages, phone dumps, original sound banks and removed legacy code.
- Both APKs report code 304, SDK 29 minimum and arm64-v8a. Package IDs remain
  `io.github.eriark.abyssme` and `io.github.eriark.abyssme.phone`.
- Both signatures verify with the unchanged certificate SHA-256:
  `722b6f8e74090bd3895eb0bc76433333c637e881758fc10ac276dd214499c38f`.
- Fresh dependency-source preparation resolved all 118 artifacts; its inventory
  matches beta.4. All 49 native source archive hashes matched the lock. Unchanged
  dependency/native source bundles are reused. The application archive is exported
  from the new release tag. Native source restoration was not repeated this pass.

Local logs: `build/beta5-release-build.log`, `build/beta5-sources.log`.

## Final Signed APKs on Retroid

Retroid Pocket Classic, Android 14. Handheld: 1240x1080; Phone also exercised
1080x1240 portrait. Input was injected through ADB; this is not physical-phone
ergonomics, human controller acceptance or audio-listening verification.

- Both final signed variants installed with `adb install -r`. Handheld upgraded
  beta.4 and retained its **39-game** library. All **323 readable external files**
  retained identical hashes immediately across the upgrade. Two Android-protected
  Mophun directories could not be hashed; no full private-database/save audit is
  claimed. No app data was cleared.
- Handheld Gallery, Grid and List opened normally; fresh captures are included.
- Phone Age of Empires II Deluxe **02.00.35** reached Quick play gameplay.
  Touch navigation moved the map; portrait preview/Keep preserved the picture.
  Dark numeric controls and the small shortcut reveal button were inspected.
- The Phone shortcut row appeared on request and collapsed after idle time;
  the game picture stayed in place. Existing hidden-shortcut preferences remained
  respected. The common menu and confirmed restart worked: the Java process
  changed from PID 5352 to 5738 and the game returned through its startup screens.
- Signed Handheld Snakes reached the Single Player menu; the common menu and
  confirmed exit worked. Mophun Deep Abyss T300 reached its first gameplay screen.
  These are launch checkpoints, not native full-game or save acceptance.
- The temporary production Phone package was removed with `-k` after testing.
  Its data remains; the official installed variant is Handheld beta.5, code 304.
  Existing isolated developer packages were not purged.

physical RG Cube acceptance were not verified. Native Asphalt cold relaunch and
broader Symbian compatibility remain open. Restart is a recovery action, not a
promise that all black screens are fixed. No measured FPS improvement is claimed.
Games and firmware are not distributed.
