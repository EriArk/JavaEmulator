# AbyssME 0.7.0 Beta 9

Beta 9 adds **independent right-stick mapping** for physical controllers.

Open **Controls → Controller mapping → Sticks** to assign the right stick’s directions and diagonals to phone keys, soft keys or Fire. **Identify** detects right-stick movement; pressing R3 remains a separate input. Bindings are saved per game, and existing profiles keep their settings with the new directions unbound.

The shared input path supports Java ME, Mophun and Symbian/N-Gage. This maps stick directions to digital keys; it does not add proportional analog camera support to games.

- **ARM64:** `AbyssME-0.7.0-beta.9.apk` — Java ME, Mophun and experimental Symbian/N-Gage.
- **ARMv7:** `AbyssME-0.7.0-beta.9-armv7.apk` — Java ME and Mophun, without Symbian.

Android 10+ is required. Both update the existing app in place.

Tested with automated input and a virtual joystick on Retroid; physical dual-stick hardware testing remains pending. Source bundles and SHA-256 checksums are included.
