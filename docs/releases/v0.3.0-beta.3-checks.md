# 0.3.0-beta.3 Release Verification

Date: 2026-10-15. Version code **302**, Android 10+, arm64-v8a.

## Candidate History

Beta.2 was withheld before publication: installing ordinary SIS games on the
same phone hid a registered N-Gage card from the launcher. Its source tag remains
unchanged. Beta.3 recognizes registered card executables independently, including
the alternate `_1` layout, using the card's `game.id` marker. The existing mounted
card path remains a fallback. Catalog, library and removal classification use
the same rule; arbitrary hidden system apps are not exposed.

## Fresh Build Checks

- Clean combined signed build from the pinned restored native source tree:
  `-PsymbianRelease=true -PsymbianSourceDir=build/symbian-source-check`.
- Both release APKs, both lint tasks, both JVM suites and `verifyProductionApks`
  passed. JVM: **25 tests per variant**, zero failures/errors. Lint: zero errors,
  **402 Handheld / 409 Phone warnings**, not a warning-free build.
- APK content guards confirmed the engine/notices and rejected private games,
  phone dumps, old sound banks and removed legacy engine payloads.
- Both APK signatures verified with the unchanged SHA-256 certificate:
  `722b6f8e74090bd3895eb0bc76433333c637e881758fc10ac276dd214499c38f`.
- Native tests executed on physical Retroid: capture cleanup (12), capture
  routing (27), and card identity (13 assertions). The latter covers mixed SIS
  folders, multiple cards, alternate builds, missing files and path exclusions.
- Local build log: `build/beta3-release-build.txt`.

## Final Signed APKs on Retroid

Retroid Pocket Classic, Android 14, 1240x1080. Touch/key input below is injected
through ADB, not human controller or audio-listening acceptance.

- Both production variants upgraded code 301 to 302 with `adb install -r`.
  Android reports the expected production IDs, code 302 and variant version names.
- Opening System files refreshed existing phone indexes. Snakes reappeared
  without reinstalling it, alongside the unrelated SIS game on the same phone.
  It launched through the library, accepted menu input and reached its game field.
- Handheld library contains nine entries: three Java games, two Deep Abyss
  Mophun variants, three SIS/SISX games and one original N-Gage card. This is
  eight distinct titles, not nine different games or nine compatibility passes.
- Phone retained its two entries, Gamepad layout and hidden Display/Screenshot
  shortcuts. Ghost Recon reached its title screen, with Menu still available.
- Fresh, inspected screenshots: [beta.3 captures](../../screenshots/releases/v0.3.0-beta.3/).

The preceding same-day [beta.2 candidate checks](v0.3.0-beta.2-checks.md) record
the public import workflow, earlier code-300 upgrades, Java/Mophun/SIS startup
checks, both Phone decks and Android's haptic request. Those observations are
not represented as repeated beta.3 checks. Earlier development test matrices
remain linked there separately from signed-APK testing.

## Sources and Limits

The matching app source contains the new host fix. Native pin and Android
dependency inputs are unchanged; their verified source bundles are reused.
The same-day dependency preparation resolved all 118 artifacts and verified 49
native archives against the lock. A second fresh native restoration was not run.

ES-DE, Samsung Android 16, perceived haptics, physical-controller ergonomics,
audio, full games and broad Symbian compatibility remain unverified. Intermittent
Ghost Recon startup and native Asphalt cold relaunch remain open. Games and
firmware stay private. This is an experimental beta, not universal compatibility.
