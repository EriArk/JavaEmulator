# AbyssME 0.7.0 Beta 4

A focused fix for **Compatibility settings** opening the game instead of its editor.

- The library card's Advanced panel now recognizes Android's standard edit action.
- Settings opened after first game preparation explicitly request the compatibility editor.
- **Try in game** and normal game launch keep their existing behavior.

One signed ARM64 APK, Android 10+, package `io.github.eriark.abyssme`, code **318**.
Install over the official app without uninstalling. Games and firmware are not included.
Existing Beta 3 compatibility limits remain, including N95 cold startup.

Targeted navigation checks cover both entry points; see the
[verification report](v0.7.0-beta.4-checks.md). Matching app and unchanged dependency/
Symbian source bundles accompany the APK. No new engine or dependency is introduced.
