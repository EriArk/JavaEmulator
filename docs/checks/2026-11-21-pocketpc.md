## Device checks

- Changed image rotation to 90 degrees in the shared display panel. The rotated stylus selected units and operated the game menus. Input injected through the connected Xbox controller and the on-screen directional pad scrolled the map. Direct hand operation was not observed.
- The original PocketHLE FMOD path returned success without emitting game audio. The adapter now decodes the supplied tracker music and PCM samples. Android playback capture of the title/menu sequence measured −26.9 dB mean and −5.3 dB peak over 12 seconds.
- Saved the random map through the in-game menu. After restarting the app, Saved Game listed the 170,542-byte save, the game loaded it and the units and map reappeared. The user's 64 previous managed card paths were retained. One additional game card is on the device.
- All 13 Android instrumentation tests in LibraryTabsTest and HandheldCycleTest passed on the updated device, including navigation, format recognition and the populated-library backup round trip.
- Local evidence includes the extracted package inventory, headless logs, screenshots, audio recordings, private builds and instrumentation output in `build/checks/pocketpc/`. The source repository contains the adapter and verification notes. Firmware, games and APKs are not part of this change.

The observed match used the alternative executable. Complete campaigns, a full match and compatibility with games specific to Windows Mobile 2003 SE or later versions remain unverified.
