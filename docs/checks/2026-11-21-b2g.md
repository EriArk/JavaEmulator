# Firefox OS and KaiOS on Retroid Pocket Classic, 2026-11-21

Updated the existing private combined ARM64 debug installation on Android 14. Final APK SHA-256: `4d807b1f1e54734fba142ddb2b84c913901dc376a33f195a96a46fc827e4912c`. The ZIPs ran offline in Android System WebView on the Retroid. The device did not run Gecko or a full Firefox OS or KaiOS system. [Runtime and import formats](../../engines/b2g/README.md).

## Shared host checks

- A local fixture separately verified a dedicated Web Worker, service-worker installation with a fetch from the package, offline status, and the legacy manifest self-query. Those checks exercise APIs and are separate from the game results.
- Twelve device instrumentation tests passed on the final APK, covering navigation, format routing, unique card IDs and isolated library backup/restore. All 57 pre-existing card paths survived, giving 61 after import. Four pre-existing webOS storage snapshots matched byte for byte. The webOS version of 2048 reopened with its prior score and board.
- Four managed cards were added to the existing combined library. Reopening the same legacy ZIP remembered the selected platform. Both platform tabs use the shared graphics and physical-controller settings, virtual keypad and per-game storage.
- Touch and Xbox input were injected on the Retroid. Hand-operated controls, a full playthrough and compatibility with an edition published specifically for KaiOS 4.x have not been verified. High scores and music preferences are the saves tested here. Camera, SIM, telephony and store-dependent behavior were outside the tests.
- Device screenshots, lossless audio, package hashes, build output and instrumentation logs remain local in `build/checks/b2g/`. The test games and APK were not added to the repository.
