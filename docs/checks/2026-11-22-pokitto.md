# Pokitto on Retroid

The existing combined ARM64 debug installation was updated in place on a Retroid Pocket Classic running Android 14. The final APK SHA-256 was `9982e3ea9dc58393a017968461249592f7d7989e41da835922512da2e1f31784`. The [native adapter](../../engines/pokitto/README.md) runs PokittoEmu v1.0.5 inside AbyssME. Games, SD media and the private APK were kept outside the repository.

After the final in-place APK update, MicroCity reopened the saved road. Selecting the saved disk through **More → Mount SD image** restarted the game, retained the disk hash and allowed the same city to load again.

The first test exposed an empty EEPROM starting games at zero volume. Raising the guest volume produced sustained audio. New EEPROMs now use the volume and countdown defaults from the [original Pokitto loader](https://github.com/pokitto/PokittoLib/blob/4406a4f2ff39acc42beea39628f4722e4f9d2b9e/Loader/miniload.cpp). Existing settings are preserved.

## Controls and library

The on-screen layout exposes the D-pad, A, B, C and Flash. Touch C inserted a credit and started combat. Android input events sent through the attached Xbox Wireless Controller device node moved the ship and fired. Reassigning Xbox X to guest A confirmed the volume dialog after a cold launch. The CRT display profile also persisted. Tests used the digital audio output and injected device events. Manual button feel, analog speaker quality and complete campaigns remain unverified.

On the platform grid, controller input moved focus from Gamebuino Classic to Pokitto. The transparent Pokitto photograph gained a glow and grew. Selecting it opened the Pokitto library with the scrolling platform tabs. [Retroid launcher capture](2026-11-22-pokitto/launcher.png).

All 19 tests in LibraryTabsTest, PlatformControlsTest and HandheldCycleTest passed. They included reimporting a ZIP with SD companions after a loose BIN, populated backup/restore and touch layouts in both orientations. A separate ARM64 core run added a 54,433-byte music file to a copy of the saved city’s disk. Reading the FAT chains confirmed that the new file matched its source and the guest save retained SHA-256 `6a5f53f03920f7c00dd028260dbaf9c37eea758a9207990d803863a7ad76b2ed`. The 72 pre-existing managed cards remained on the device alongside both Pokitto games. Public APK availability was not rechecked.
