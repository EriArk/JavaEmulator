# Original Thumby on Retroid

The existing combined ARM64 app was updated in place on a Retroid Pocket Classic running Android 14. Its application ID is `io.github.eriark.abyssme.dingoocheck.debug`. The final private APK has SHA-256 `3e59d18c77722ab3eb00f301902a43fb551afcbdb8ec011871d8e0e61bdc0fc5`. The binaries, firmware and games are local build inputs. Public APK availability was not rechecked.

The board, USB serial implementation, firmware and guest libraries come from the [TinyCircuits editor](https://github.com/TinyCircuits/TinyCircuits-Thumby-Code-Editor/tree/5b3710cc100a). The fixtures are unmodified scripts from the [original Thumby game catalog](https://github.com/TinyCircuits/TinyCircuits-Thumby-Games/tree/4aeb116ae161ca7d46d304a1dbdbfa0f462d774f).

| Game | Device evidence |
| --- | --- |
| Alien Invasion | Android Open imported the game folder as a ZIP with its Python helper. Its embedded arcade video produced a cover. Xbox controller events selected Start, moved the ship and fired. A 16-second digital output capture spanning gameplay and pause contained half-second windows up to −17 dBFS RMS after a 30 Hz high-pass filter. [Combat](2026-11-22-thumby/alien-invasion.png). |
| 4Connect | A loose Python file opened as a separate game. Setting on-screen controls to **Always**, trying the setting and keeping it exposed the D-pad and B/A. Touch input advanced through the menus and placed a piece. [Board and touch deck](2026-11-22-thumby/4connect.png). |
| Donut Clicker | The game’s counter survived a force-stop and APK update with seven donuts. The game then wrote a counter of 11 to its own flash save. After force-stopping the process and opening the script again, the display showed [11 donuts](2026-11-22-thumby/restored-eleven.png). |

The controller check used injected Linux input events through the attached Xbox Wireless Controller node. Audio verification used captured Android output. Manual button feel, analog speaker playback, link multiplayer and full-game completion were not assessed.

All 22 Android instrumentation checks passed before the final sticker correction. These include loose and zipped game identity, flat archives with helper scripts, tab navigation, touch layouts and a populated backup/restore into an isolated directory. The corrected APK had identical DEX, native libraries and Thumby runtime asset contents. Controller input opened the [focused tile](2026-11-22-thumby/launcher.png) and displayed the [three-game shelf](2026-11-22-thumby/shelf.png). The final library contained the previous 96 managed entries plus the three new games. Both pre-existing Epoch checkpoints retained their SHA-256. The temporary instrumentation package was removed.
