# Platform lifecycle audit on Retroid Pocket Classic, 2026-11-20

## Installed library and update

The local ARM64 0.8.0-beta.1 combined build uses `io.github.eriark.abyssme.dingoocheck.debug`. After the old APKs were removed with Android's keep-data option, the combined build had zero Java ME or Mophun catalog rows. Android had retained the old applications' separate data directories. Updating the same application ID keeps the library accessible.

Consolidated the primary catalog's 42 games and additional distinct games from the previous installations into 54 Java ME and 6 Mophun entries. The recovery used installed content, available per-game settings and saves. Three Mophun titles were reimported from matching original bytes. Restored Inotia and Metal Slug with their WIPI package data, and the N95 and N-Gage QD virtual phones with their installed games. A fresh Frozen Bubble SISX installation selected the N95 and added the game to the Symbian tab. It reached its start menu on the device. The retired data directories remain available separately.

Reinstalled the identical APK with `adb install -r`. Compared 8,893 game, settings, save, phone and firmware files by SHA-256, and compared all 60 database rows and seven source aliases before and after. All matched. The subsequent updated APK also installed over the populated library. All 8,895 files present immediately before this second update, 60 rows and seven aliases matched afterwards. After the update, 1916 Dogfight reached the HeroCraft splash and Snakes reached its N-Gage startup screen. These builds use the same database version.

On first use without a saved profile, a Mophun card initially redirected to a separate settings screen. The updated build initializes the profile in the library and opens the requested page directly. Confirmed first-use Display on Boulder Dash and Controls on V-Rally 2, including the physical controller profiles and mapper. ## Follow-up on the same Retroid installation

The local ARM64 build extends **Back up library** and **Restore backup** to WIPI/SKVM, Dingoo A320, Gemei A330, P/ECE and GP32. Individual games can be selected on restore. The archive contains managed packages, card metadata, artwork when present, settings, user-provided system files and writable guest data. Existing saves and settings take precedence on restore. Symbian and N-Gage continue to use their phone backup flow.

On Retroid, exported the 20 installed handheld cards and restored them into a separate directory. The five platforms were visible to the library providers after restore. Compared the stored packages, writable data and system files by SHA-256, checked per-game configuration restoration, then repeated the import and verified that a newer destination BIOS survived. The in-place update preserved all 60 primary catalog rows, seven source aliases and 8,898 checked files.

The original Aquaplus 1.20 updater produced the same 2 MiB PFI as upstream `mkpfi` (SHA-256 `ddc99cec66679f23a335e65c45c99ff8a621fe4f7c85db5bf378c391c0d58cc2`). Imported P.K.O. against that base. Installed Digger and 7 Days Salvation from separate ZIPs with nested test assets and an empty directory, reimported each, verified the paths, and removed the test cards in isolated storage.

Android file opening and game-folder indexing recognize managed handheld formats, including carrier ZIP descriptors and the signatures of the two supported raw firmware types. Opening a package with more than one matching platform offers a choice. Opening Digger from an Android VIEW intent launched its Dingoo activity. The game library uses a horizontally scrollable tab strip; on Retroid, Java ME measured 224 pixels (112 dp) and the selected GamePark GP32 tab was fully visible at the other end. All 45 focused Android checks passed on the final installed APK. They covered the real handheld fixtures, the library importer, folder indexing, library tabs and the transfer screen. These checks exercise import and storage. The individual game reports above cover the previously tested audio, guest saves and controller paths. LGT gameplay, the two black-screen Gemei titles and C2S gameplay remain open. These are compatibility results for particular games. No public build was made.
