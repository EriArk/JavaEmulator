# Arduboy and Arduboy FX on Retroid

The combined ARM64 build updated the existing AbyssME installation on a Retroid Pocket Classic running Android 14. Its SHA-256 was `06075e3082ad8e1dda3df39af019d529f1e7cb2a64bbc1b36737bcb783870dd9`. The [adapter](../../engines/arduboy/README.md) builds Ardens v0.25.12 from source. The private APK and the games stayed off the public release page.

| Package | Import and play |
| --- | --- |
| ArduGolf, SHA-256 `490762efcb30f85473443d91c16d22174f4cfab66371ad68e27c83dd1a9fd879` | Opening the HEX in Android installed a card. A selected Play and entered hole 1, par 2. The library captured a gameplay preview. |
| Dazzle Dash 1.1, SHA-256 `a4201ed9820cae389c8d7a4dd1338b90a1def6e90bc833be9eedce3b33318358` | The original .arduboy package kept the program, flash data and save seed. Its manifest supplied the title and screenshot. New Game entered Sleepy Meadow with a running timer and three hearts. |

Both games use the 128 × 64 guest display. With on-screen buttons enabled, tapping A resumed play, the D-pad moved the character and B opened the guest pause menu. Android input events were injected through the attached Xbox Wireless Controller device node. The default A started a game, the hat moved the player and B paused. Assigning controller X to Arduboy B in the shared mapper also paused the running game. A twelve-second digital capture during Dazzle Dash measured −38.9 dB mean and −23.2 dB peak. A second eight-second capture on the final APK measured −37.2 dB mean and −23.2 dB peak. Analog speaker output and manual button feel were outside this check.

The first build exposed a save-state error when switching between games in one process. Ardens cached the first game's libretro buffer size. The final adapter streams the game's actual state and atomically replaces its slot. It read the initial padded slots, wrote 92,634 bytes for ArduGolf and 92,654 for Dazzle Dash, loaded both in alternating order without restarting the process, then loaded Dazzle Dash again after a cold restart. The restored screens showed hole 1 and the guest pause menu in Sleepy Meadow. The ArduGolf EEPROM save was a separate 1,163-byte file.

All 68 previously recorded managed cards survived the in-place update. Reopening the two games reused their cards, bringing the count to 70. These checks cover the opening game scenes. Completion of a campaign and a game-triggered FX flash save in a later level remain unverified.

On the ArduGolf title screen, B muted the speaker and A started Play, which writes the game's audio preference to EEPROM. After a process restart, the title screen still showed the muted speaker. Enabling sound and repeating the same sequence restored the enabled speaker icon on the next cold start.

The shared display menu kept the CRT setting across a process restart. The original Pixel sharp setting and default controls were restored after the test. The Retroid was left on the Arduboy / FX tab with both games available.

All 17 Android tests in LibraryTabsTest, PlatformControlsTest and HandheldCycleTest passed on the final combined APK. They covered the platform tabs, touch targets in both orientations, bare and wrapped package identities, FX manifest handling and the populated library's backup and restore. The restore used an isolated destination and compared source and restored game files by hash.
