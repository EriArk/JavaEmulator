## Import and preservation checks

- Opened each loose VXP from Android and launched its managed copy. Opening the MRE device sticker showed both games and their runtime previews.
- Ten device instrumentation tests passed (`LibraryTabsTest` and `HandheldCycleTest` with `handheldCycle=true`). These included loose versus ZIP identity, one card after reimport, folder-index identity, and an isolated backup/restore of the populated library including MRE packages and data.
- All 51 previously recorded managed card paths remained present. The final count was 53. The sampled pre-existing Dingoo save kept its SHA-256.
- The APK exposes a distinct MRE game process, uses the shared graphics/input profiles and creates a writable drive tree per game. Guest file paths are restricted to that tree. Firmware import is unnecessary for these games.

Controller input was injected through Android or the Xbox event device. Hand-operated button feel, a complete playthrough, and other MRE screen sizes have not been verified. The engine's checkpoint format drops active audio voices and open host files on load. A separate early core run advanced the 11 entries in a game archive, including Crossfire, through 420 frames each; that is not a gameplay result for those entries.
