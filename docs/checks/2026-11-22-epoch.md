# Epoch Game Pocket Computer on Retroid

The existing combined ARM64 installation was updated in place on a Retroid Pocket Classic running Android 14. The private APK has SHA-256 `e7822d342515fe8a13ad6a47fdc5740714bcb234fe943d389dda7a0ac0ddf462`. Source integration uses the [pinned MAME subset](../../engines/gameking/README.md). The public release state was not rechecked.

| Input | Result on the device |
| --- | --- |
| Supplied `gamepock.zip`, containing the 4096-byte `egpcboot.bin` (CRC32 `ee1ea65d`) | Android Open created the built-in programs card. Without a cartridge, Start opened the graphics editor and Select switched to the sliding puzzle. Touch Start shuffled the board and started its timer. Saving, force-stopping AbyssME, reopening the ZIP and loading the state restored the board and the saved timer. [Restored puzzle and touch controls](2026-11-22-epoch/puzzle.png). |
| [1st Pokekon Demo by Chris Covell](https://www.chrismcovell.com/GamePokekon/pokedemo.html), original ZIP containing a 16 KiB cartridge (CRC32 `c008102c`), source and readme | The ZIP created a separate cartridge card. Controller input selected the music editor, started playback and navigated to the Epoch Land scrolling scene. A six-second digital output recording during music playback contained half-second windows between −21 and −17 dBFS RMS after a 30 Hz high-pass filter. [Epoch Land](2026-11-22-epoch/epoch-land.png). |
| Retail Astro Bomber, supplied as `astrobom.zip` (8 KiB ROM, SHA-1 `453a0f3c0952ebd8e691316c39960731f1996c09`) | Android Open imported the ZIP using the existing BIOS. Touch Start entered level 1. Xbox D-pad events moved the ship vertically and face-button events fired projectiles. A 13-second Android audio capture during play contained effects reaching −20 dBFS RMS in a half-second window after a 30 Hz high-pass filter. Loading the 204,889-byte checkpoint after a force-stop and cold launch returned to the level. [Gameplay on Retroid](2026-11-22-epoch/astro-bomber.png). |

The platform launcher uses the real device photograph and enlarges it with an accent outline when focused. The controller opened the separate Epoch shelf from the [focused tile](2026-11-22-epoch/launcher.png). The touch layout exposes the D-pad, buttons 1–4, Select and Start. The physical checks used input events through the attached Xbox Wireless Controller node. Button feel and analog speaker playback were not assessed.

A standalone ARM64 core run completed 600 ticks each for the BIOS and homebrew demo, with 599 frames at 75 × 64 for each. Both states serialized and restored. All 21 Android instrumentation tests passed. They covered the cartridge header, renamed firmware, identical raw/ZIP game identity, shared backup/restore, navigation and touch layouts. All 93 previously managed cards remained installed alongside the two Epoch entries. The prior Hartung Falling Block checkpoint retained its SHA-256 and loaded its saved piece in the updated app. The temporary test package was removed. The retail check used the same installed APK and covered level 1. Firmware, cartridges and compiled binaries stay outside Git.
