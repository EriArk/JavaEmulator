# ESPboy Little Game Engine on Retroid

The combined ARM64 test build was updated in place on a Retroid Pocket Classic running Android 14 under `io.github.eriark.abyssme.dingoocheck.debug`. The private APK has SHA-256 `82ed65ff5d1045ab14daede3f7b686935884e7bd20cb4baccae3cd8769b44c94`. Public release availability was not rechecked. Games came from the [ESPboy device catalog](https://github.com/ESPboy-edu/ESPboy_little_game_engine/tree/3adf0c875f999de2f2f99c2815e825cb2a3bfbb8/data).

| Game | Import and device result |
| --- | --- |
| NinjaEscape | Opened an arcade ZIP and then the loose LGE. Both resolved to the same game. Controller input advanced the title, attached the ninja to the rope, moved right and triggered an action with right held. A 15-second digital output capture spanning launch and gameplay contained half-second windows up to −22 dBFS RMS after a 30 Hz high-pass filter. [Gameplay](2026-11-22-espboy/ninjaescape.png). |
| Cityrunner | Imported a loose LGE. The screen ACT button started the run. Xbox X remapped to RGT paused the game after an APK update, and touch resumed the run. The kept Smooth display preset and physical mapping survived relaunch. The game wrote a record of 105 and showed it again after a force-stop and another run of 56. The final APK reopened that same record. [Restored record and touch deck](2026-11-22-espboy/cityrunner.png) · [Controller mapping](2026-11-22-espboy/controller.png). |
| breackout.bin | Opened the headerless device game from the ESPboy tab using Android’s document picker. It added a third card. The game drew bricks, ball and paddle. Right input moved the paddle and a brick disappeared. [Board](2026-11-22-espboy/breackout.png). |

Controller navigation focused the [ESPboy tile](2026-11-22-espboy/launcher.png) and opened the existing tabbed library. The sticker crops a photograph of the real device down to its acrylic housing. The two LGE games provided their own 24 × 16 library icons. The raw game acquired an automatic gameplay preview. All three appear on the [ESPboy shelf](2026-11-22-espboy/library.png). The touch deck and mapper expose the D-pad, ACT, ESC, LFT and RGT. Physical-controller checks used injected events through the connected Xbox Wireless Controller node. Audio was captured digitally. Manual button feel, analog speaker output, wireless peripherals and complete playthroughs were not checked.

The decoder read all 41 LGE containers and five raw BINs in the pinned device catalog. Gameplay verification covered the three entries above. The private host uses the [pinned SDK VM and offline Android adapter](../../engines/espboy/README.md).

All 24 Android instrumentation checks passed on the final APK. They included raw and compressed ZIP identity, overlapping back-references, icon extraction, automatic recognition of an installed cartridge, and a full populated-library backup/restore into an isolated directory. The final library contained all 101 previous entries plus three ESPboy games. Hashes of the sampled Epoch checkpoints, Thumby flash blocks and Thumby Color guest save remained unchanged. The temporary instrumentation package was uninstalled, leaving one AbyssME installation.
