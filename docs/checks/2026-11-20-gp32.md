# GP32 on Retroid Pocket Classic, 2026-11-20

Tested the private combined ARM64 debug build on Android 14 using the European stock 1.6.6 BIOS. The platform sticker opens the GP32 library tab. The Android document picker accepted the zipped Tomak card. Touch events and Xbox controller events were injected on the Retroid. The controller events went through the connected Xbox input device. Hand-operated controller feel, speaker listening and complete playthroughs remain unverified. Sixteen Android instrumentation checks passed on the combined build (3 GP32 import, 5 library navigation, 2 P/ECE, 2 Dingoo and 4 WIPI).

## GP Fight card recovery

The supplied SmartMedia ZIP ended before its compressed image was complete. The separate encrypted raw-files ZIP passed CRC. Reconstructed the card from those files, the surviving card geometry and identification data, and the directory structure from the readable FAT. The first reconstruction showed the intro and returned to firmware. The guest tried to create `GAME/GPFIGHT/MISC/CHARPASS.pas`. The original card contained the empty `MISC` directory, which the raw-files ZIP omitted. Restoring that directory allowed the game to enter combat without modifying its executable. After playing, the emulator's private writable card contained CHARPASS.PAS (36 bytes), KEY.PAD (16 bytes) and ACP.DAT (4 bytes).
