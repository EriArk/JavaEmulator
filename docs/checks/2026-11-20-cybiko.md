# Cybiko and handheld library art · 2026-11-20

The private combined ARM64 debug build was installed in place on Retroid Classic. The final APK replacement preserved 8,945 inventoried files and all 81 Java catalog rows. Cybiko packages live alongside the other handheld libraries. The public repository contains the optional bridge and build instructions. These checks did not produce a public APK.

| Configuration | Result |
| --- | --- |
| Xtreme, boot ROM 1.5.0, CyOS 1.5.08, Homerun Derby 1.1 | The original Xtreme application imported from ZIP. Completed guest setup, opened Games, started a game, reached the baseball diamond and final score. Injected Xbox-controller button and hat events through the Retroid input device. Tapped the virtual Select and Fire buttons to start another game. An Android playback capture yielded 561,152 mono samples, including 34,960 nonzero samples with a peak of 8,192. |
| Classic v1, boot ROM 1.1.12, CyOS 1.2.46, Snake Battle | Original CD application imported, appeared in the guest Games group and displayed its title on Retroid. Its game setup requests a snake file. |
| Classic v1, same firmware, Maze Dweller | Direct Android Open With import recognized a CyOS application. Reached the first playable maze on both the native host and Retroid. Sent direction changes using the controller hat on Retroid. Android playback contained 65,640 nonzero samples out of 319,488, with a peak of 8,192. |
| Classic edition of Homerun Derby | The icon imported. The guest reports that the program needs CyOS 1.3.57, also recorded in its embedded application description. That edition does not play on the tested Classic v1 system. |

The two Homerun application hashes start with `d8efd469bc7d8525` (Classic) and `bf875be2fe1d26d4` (Xtreme). Each got its own library card, original icon and game storage. The Android build exposes stable `classic` and `xtreme` machine profiles in one Cybiko family tab. Per-game storage also distinguishes the system image. No original Cybiko hardware, radio, Classic v2, human-operated gamepad session or game completion was tested.

## Artwork checks

- WIPI Inotia's recovered 120 × 110 icon matched the decoded pixels of the carrier's original `big.icon`.
- Two installed GP32 FXE icons matched an independent decoding of the column-major, bottom-up image using the GP32 palette. P/ECE's installed PKO icon matched all pixels of the author's 32 × 32 `uruto.bmp`.
- Cybiko recovered the two Homerun icons (47 × 48 and 48 × 47), including method-2 decompression. The Android test checked direct and zipped imports, repeat import identity, both firmware pairs and Snake Battle metadata.
- A bare Mega Duck Arctic Zone cartridge generated a 160 × 144 runtime preview on the Retroid.
- Nineteen Android instrumentation tests passed across Cybiko import, library tabs, artwork, import routing and populated handheld backup/restore. Java ME, Mophun, Symbian and N-Gage were not separately replayed in this check.
