became available. Retroid Pocket Classic, Android 14 / API 34, native ARM64,

result. Exact game input hashes match the [emulator samples](2026-11-10-real-games.md).

- **Selected UI regressions:** **7 tests pass in 16.707s**: four library-tab cases,

## Native N95 / Asphalt 3

The opt-in `prepareModernLcdFixture` scenario passes in **27.975s**, importing the
provided N95 archive, installing N-Gage 2.0 1.40.1557, staging Asphalt 3 and opening
the platform. Its instrumentation lifetime ends before the guest installation
finishes; that test alone is not game acceptance.

The normal Pending import / Continue workflow resumes installation. Guest
installation completes, language/sound menus open, and Instant Play reaches a
moving race. Android gamepad-source injected keys navigate and activate nitro.
The keyboard-source events did not provide the same guest navigation. Sound is
subsequently declined to keep this visual check bounded; no listening claim.

During the platform-hosted race (menu title Games), Original → LCD Soft → Keep → Resume and LCD Classic → Keep →
Resume both show changed presentation and advancing race scenes. Original → Undo
returns to the retained LCD Classic selection; Original → Keep restores the
unfiltered image. The ordinary exit confirmation returns to Pending import;
Finished indexes Asphalt3 in the N-Gage library. Reopening its library card reaches
race startup again. **That reopen retains native PID 24055, so it is not a cold
native-process launch.** These observations narrow #48 but do not close it or
establish a new production repair.

A separate **cold-process check fails to reach gameplay**: force-stop only the
isolated package, verify the native PID is absent, then launch Asphalt3 from its
library card. New native PID **26260** replaces 24055. After roughly one minute,
the guest remains blank/white; the host Back menu still responds and Display
shows **Original**, before any new LCD choice. The guest log reports
`Region rect buffer pointer is invalid!` plus unimplemented socket operations.
This correlation does not establish the root cause; the retained log has no
`KERN-EXEC` or fatal signal entry. Exit returns to the library through the ordinary
confirmation. Cold evidence: `cold-before.json`, `cold-pid.txt`, `cold-logcat.txt`
and `cold-01`–`08` captures. Prior warm progress must not be counted as cold success.
The isolated installed phone is retained for diagnosing this next.

Reviewed evidence: `n95/manual-12.png` (installation complete), `manual-24`–`28`
(menu, race, nitro), `manual-30`–`37` (presets, Keep, Undo, Resume), `manual-39`–`41`
(import completion/library) and `manual-43`–`48` (reopen to race startup).
The input journal and PID-specific logs remain private. Logs contain guest
missing-file/unimplemented-operation and OpenSL configuration diagnostics; this
is not a clean-log or complete-race acceptance result.
