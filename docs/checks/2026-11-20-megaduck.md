# Mega Duck on Retroid Pocket Classic, 2026-11-20

The private combined ARM64 debug build adds an eleventh platform to the [launcher](2026-11-20-megaduck-grid.png). On Retroid Classic with Android 14, the Mega Duck tab contains 23 games from the supplied Welback Holdings collection. Two were imported directly. The Android folder picker granted access to Download/MegaDuck and the folder scan added the other 21. Selecting the indexed 2nd Space card installed it and reached the Fast/Slow mode selector.

## Collection and cold start

The ZIP ends partway through Zipball. Verified the length and CRC of the preceding 23 cartridges against their local ZIP headers. Each ran in a separate host process with the same pinned SameDuck sources and Android core patch. The test supplied Start, direction and action inputs for 720 frames and checked state serialization and loading. All 23 produced changing video and varying audio. These short tests cover startup and initial interaction.

Magic Maze could show a blank picture or stall with a steady audio sample at startup. The unmodified work RAM initialization stalled the fixed-input test at seeds 9, 11 and 13. Clearing only high RAM still failed at seeds 9 and 11. Clearing work RAM on reset let Magic Maze produce changing video and sound at all 24 seeds tested (0 through 23). The same initialization is used for every cartridge. The 48 kHz Android path groups the core's individual stereo samples into blocks before submitting them to AAudio.

## Installation, profiles and backup

The first in-place update preserved all 8,904 checked files, 60 primary catalog rows and their source aliases. After adding the new platform's games, folder and checkpoint, the final in-place update preserved 8,912 files and 81 catalog rows. The additional platform cards have their own content-addressed store. The final APK passed all seven focused Android tests, including platform tab navigation, binary/archive routing and restoring the populated handheld library to an isolated directory. The backup check compared installed cartridge and checkpoint bytes. Removed the temporary instrumentation APK and confirmed a single AbyssME package on the device.
