# Thumby Color on Retroid

The combined ARM64 app was updated in place on the Retroid Pocket Classic running Android 14. It uses application ID `io.github.eriark.abyssme.dingoocheck.debug`. The private APK has SHA-256 `b40b40cf5743ecdb376b1ed198e2f33603038858a6e5fbe32c310da0d334b094`. Public release availability was not rechecked. The fixtures were unmodified game directories from the [TinyCircuits Color Arcade](https://github.com/TinyCircuits/TinyCircuits-Thumby-Color-Games/tree/e675b0925338d1368c8054b7ad1fe8a64cdb003d), opened through Android as individual ZIPs.

| Game | Device result |
| --- | --- |
| FroggyRoad | Controller D-pad input advanced the score to two. The on-screen right bumper advanced it to three. The touch deck exposed both bumpers and Menu. The game saved world 99 and a high score of three in world 1. Both survived a force-stop, reimport and in-place APK update. With the Smooth display setting and touch controls kept, Xbox X was remapped to RB in the shared mapper. After the update, X advanced the frog again. [Restored scoreboard](2026-11-22-thumby-color/froggy-road-save.png) · [Controller options](2026-11-22-thumby-color/controller-mapper.png). |
| BustAThumb | The unmodified game drew its background through typed framebuffer views. Xbox A started the game, the D-pad changed aim and further A presses fired bubbles. The score reached 70. The launcher extracted its animated arcade preview as cover art. [Game in progress](2026-11-22-thumby-color/bust-a-thumb.png). |

Two scrcpy FLAC captures of Android output covered the title music (RTTTL) and in-game WAV effects. After a 30 Hz high-pass filter, the loudest half-second windows measured −3 dBFS RMS in the title sequence and −23 dBFS during play. Separate four-second measurements counted 23 and 27 frames per second presented to the canvas in the title and board scenes, respectively, with the game requesting 30. These are short samples.

The input checks injected events through the attached Xbox Wireless Controller's Linux input node and through Android's touch input. Manual button feel, analog speaker output, multiplayer and full-game completion were not tested. The embedded host executes MicroPython bytecode with bounded buffer access for portable Viper routines. RP2350 machine code and general Viper compatibility are outside this result. [Host and build notes](../../engines/thumby/color/README.md).

Controller navigation focused the [Color tile](2026-11-22-thumby-color/launcher.png) and opened its [two-game shelf](2026-11-22-thumby-color/library.png). All 23 Android instrumentation checks passed, including ZIP routing, package identity with and without a wrapper directory, controller defaults, and backup/restore of the populated library to an isolated directory. All 99 previous managed entries were present among the 101 final entries. The two existing Epoch checkpoints and three original Thumby save blocks retained their hashes. The temporary instrumentation package was removed, leaving one AbyssME installation. A second run of the documented runtime build from the pinned checkout produced byte-identical staged files.
