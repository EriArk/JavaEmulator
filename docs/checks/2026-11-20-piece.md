# Aquaplus P/ECE on Retroid Pocket Classic

The local ARM64 Handhelds debug build on Android 14 included the P/ECE, WIPI, Dingoo and Symbian build options. Selecting the P/ECE sticker on the [eight-platform grid](2026-11-20-piece-grid.png) opened its tab in the ordinary library. The tab strip scrolled to show the selected platform. The APK, firmware, games and gameplay captures remain local.

| Check | Result |
| --- | --- |
| Import | Added the 2 MiB System 1.20 image through Android’s document picker, followed by the author's P.K.O. 1.11 ZIP. The package manifest requested pko.pex, pko.dat, pko.sav and drum.arc. The base image and game appeared as separate cards. |
| Game and controls | Opened the game card, selected P.K.O. in the guest launcher, chose a character and entered the shooter stage. Horizontal direction, A and Start operated through events injected into the connected Xbox controller input device. In the common Controls menu, set on-screen buttons to Always and kept the preview. The touch deck resumed combat and opened the guest pause menu again. |
| Profiles | Set the CRT display mode and bound physical X to guest Start using the shared mapper. After a cold launch, the touch deck and CRT scanlines remained visible and pressing X paused the stage. The saved custom profile mapped Android X (99) to the Start deck key (9). |
| Audio | A 24-second Android playback recording covering character selection and combat measured −19.7 dBFS mean and −5.8 dBFS peak. |
| Flash persistence | For a second card, used upstream pfar to add the executable, graphics and music to a fresh image, omitting its initial score file. P.K.O. created pko.sav in the card's writable flash. After force-stop, cold launch and reopening the guest game, the flash hash and modification time matched the previous run. pfar extracted all 120 bytes of the score table, matching the author’s initial file. The original imported image retained its hash. |
| Exit | Exited the running guest via the AbyssME game menu and returned to the P/ECE game list. |

On the same device the P/ECE import suite passed two tests, the library tab suite five, WIPI four (including the SKVM slider), and the Dingoo import suite two with Digger. The P/ECE checks included loose PEX and multi-file ZIP imports, repeat import and base image integrity.

The test covers the opening stage and the guest's initial score file. A full playthrough, a new personal high score, hand-operated controllers, the 512 KiB firmware edition and other titles remain unverified. The core models flash persistence and currently has no save-state serialization. USB, infrared and hardware peripherals were outside the check.

The system image came from [Aquaplus’s 1.20 updater](https://aquaplus.jp/piece/dl/update120.exe), SHA-256 `ef75353156686a66b2c2690656a84d2ce80d4b49e563ac5c283727931252aa3e`. The test image built with upstream mkpfi had SHA-256 `ddc99cec66679f23a335e65c45c99ff8a621fe4f7c85db5bf378c391c0d58cc2`. The [author’s P.K.O. distribution](https://github.com/zurachu/pko/releases/tag/v1.11) had ZIP SHA-256 `63052cc18e20154f5ac4b9b1de2962e8fd593869895b38afa8b2821ca03de5a5`.
