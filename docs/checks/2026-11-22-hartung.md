# Hartung Game Master on Retroid

The private ARM64 build was installed over the existing combined AbyssME package on a Retroid Pocket Classic running Android 14. Its SHA-256 is `a82e0d8470a904176fb558fd8efae1b618af923f6e787a37a48f7e9f05aabb55`. The adapter uses the Game Master driver from the same [pinned MAME core](../../engines/gameking/README.md) as the two GameKing models. No public APK was published or release availability rechecked.

## Library and controls

Android Open imported the supplied `gmaster.zip` and 18 individual game ZIPs. The library listed 19 entries. The 74 managed package directories recorded before the in-place upgrade remained present. An Xbox controller device event selected the [focused platform tile](2026-11-22-hartung/launcher.png) and opened the scrolling library tabs.

- In Bubble Boy, an Xbox Start event opened Configuration. A D-pad event changed the selected level from 1 to 2. Start reached the level 2 ready screen. A separate capture of Android digital output contained sound during interaction with the game.
- In Falling Block, setting on-screen buttons to Always exposed the D-pad, A, B, Select and Start. Touch started the board and moved a piece. More → Save state wrote 200,209 bytes. After force-stopping the app and reopening the same ZIP, More → Load state restored the piece and counter. On the final APK, opening the same cartridge as a loose ROM loaded the same checkpoint and retained its touch preference. [Restored board](2026-11-22-hartung/falling-block.png).
- Hyper Space reached level 1 with a changing score under controller input. Digital output remained silent during the sampled gameplay. A longer standalone run of 14,400 emulation ticks with input also returned zero PCM. Sound on original hardware was not compared.

Controller checks injected Linux input events through the attached Xbox Wireless Controller node. They establish input routing on Retroid. Physical button feel, analog speaker playback and full campaigns were not checked.

## Core and regression checks

A separate ARM64 harness on the Retroid ran 600 emulation ticks per supplied cartridge. Every game returned 599 frames at 61 × 64, changing image content and a successful state serialization and restoration. Seventeen produced nonzero audio samples. The same rebuilt core also ran one GM-218 and one GM-220 cartridge with their previous 48 × 32 and 160 × 160 frame dimensions, audio and working checkpoints.

All 20 tests across LibraryTabsTest, PlatformControlsTest and HandheldCycleTest passed on the updated device. They cover platform navigation, virtual button layouts, routing of raw cartridges and zipped firmware, reimport identity and populated library backup/restore including system firmware, profiles and the saved state. The instrumentation package was removed after verification. Firmware, games and native binaries remain outside Git.
