# M3G shader specialization and partial readback, 2026-10-13

Research branch only; main keeps the existing engine. No license change,
public APK, private combined-build distribution or release is part of this batch.

## Changes

- Build GPU programs for the actual packed texture count (0-4), ordinary or
  extended lighting, and a dedicated sprite path. Unused texture calculations
  and the mesh/sprite branch are removed at compilation, not by dropping game
  features. Programs are reused within the owned context: 11 possible active
  variants, plus two generic diagnostic variants. No unbounded shader cache.
- Reapply state when changing programs; context-loss recovery recreates programs
  and replays immutable draw data before committing any CPU pixels.
- Read and commit only the union of color-writing scissor rectangles. Preserve
  surrounding pixels and gaps; depth-only passes copy no color. Required depth
  readbacks remain full-size. This helps clipped/sprite work, not every scene.
- Pack sprite DDA lookup indices into a reusable heap array, then copy them in
  bulk to each draw's owned replay buffer. Fractional sampling stays unchanged.

Original-engine inspection revisited scissor/viewport handling and material
state. No EPL implementation was copied. Rectangular readback follows the
[Khronos GLES3 API](https://registry.khronos.org/OpenGL-Refpages/es3.0/html/glReadPixels.xhtml).

## Same-APK Comparison

Retroid Pocket Classic, Android 14 / Adreno A12, non-debuggable measured APK.
Each of 34 fixtures warms 256 frames, then measures five batches of 32 frames.
Reference disables specialization and partial reads; optimized enables both.
Both runs include the new bulk sprite packing, so this comparison does not
attribute its separate contribution. Resolution, filters and scene inputs match.

| Scene | Generic/full read, ms | Specialized/partial read, ms | Fresh original, ms |
| --- | ---: | ---: | ---: |
| RGB nearest 320x240 | 1.097 | 1.017 | 0.845 |
| RGB linear 320x240 | 1.095 | 1.012 | 0.872 |
| Flat lighting 320x240 | 1.458 | 1.102 | 0.869 |
| Two-sided lighting 320x240 | 1.689 | 1.119 | 0.879 |
| Sprites 240x320 | 1.623 | 1.393 | 0.953 |
| Sprites 320x240 | 1.491 | 1.349 | 0.947 |
| Multi-draw 320x240 | 1.887 | 1.658 | 1.236 |
| Material churn 320x240 | 1.808 | 1.645 | 1.260 |

All **34 before/after pixel CRCs match**, also matching the preceding candidate
checkpoint. Flat/two-sided fixtures cost 22-34% less, sprites 9-14% less; most
ordinary scenes improve by 5-13%. Four-texture scenes improve only 0.4-1.9%,
within a range where run-to-run noise matters. These are synthetic frame costs,
not game FPS. Sequential runs are not clock-locked or randomized trials.

The original still has lower cost: candidate overhead ranges from 12% to 57%
in the 32 comparable fixtures. Original skips two four-texture fixtures because
its texture-unit limit is lower. **No native-parity or production-readiness claim.**
Partial reads reduce the landscape sprite fixture's transferred pixels by about
7%; other full-viewport fixtures still read the whole target. The rectangle
regression test independently checks exactly 105 copied pixels out of 2,613.

## Game Checks

The final APK reaches Deep: Submarine Odyssey Java's opening fishing gameplay
on Retroid, with the boat, station, HUD and wake effects visible. A 35-second
capture with fourteen Right long-presses (600 ms apart) shows camera movement.
It presents 60.00 surface buffers/s, maximum interval 16.84 ms, no interval above
100 ms. Host updates average 167.5/s and largest-window target P95 is 4.241 ms.
The previous checkpoint recorded 169.6/s and 4.186 ms in a separate sample:
**this run does not establish a Deep gameplay speedup**. Camera/particle states
and sequential device timing differ. Neither update counts nor repeated surface
buffers are unique game FPS. [Capture and timing evidence](shaders-20261013/shaders-deep-candidate/).

Tower Bloxx N6270 also enters Quick Game, drops/stacks blocks and reaches the
result screen (tower height 3, population 5). The 25-second capture includes
seven Fire presses 1.4 seconds apart and the result-screen interval. Surface
presentation averages 60.00 buffers/s with no >100 ms gap; do not present this
as sustained active-game FPS. [Images and timings](shaders-20261013/shaders-tower-candidate/).
