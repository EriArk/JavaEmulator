# Retroid gameplay and profile fixes, 2026-10-13

Real Retroid Pocket Classic, Android 14 / Adreno A12. Research packages are
separate from the normal app. No game archive, private engine source or APK is
published here. The replacement engine remains experimental and opt-in.

## What Changed

- New profiles now select the existing resolution-derived font sizes instead
  of forcing the 240x320 font sizes onto every game. This fixes oversized text
  in smaller virtual screens, including Constructo Combat's 128x160 tutorial.
  Advanced font presets now include **Automatic**. Existing explicit sizes
  and imported profiles are preserved; there is no silent migration.
  This independent app fix is also applied to `main` as `9430cb0a`.
- GPU session diagnostics no longer require a live Activity. Accessing the
  weak Activity reference before initialization threw in a GPU-enabled target
  check. Diagnostics now use the application context and tolerate unavailable
  external storage. The same focused run failed once before and passes after.
- Opt-in research cadence files now use app-specific external storage, so
  non-debuggable comparison APKs can be measured without `run-as`. The capture
  tool also retains thermal-service output. Normal builds do not contain this
  telemetry. Surface polling, overflow and process/foreground checks remain.

## Real Gameplay Results

enabled GPU rasterization and hardware geometry. Existing game profiles were
retained: no FPS limit, no filtering, synchronous redraw, GraphicsMode 1.
Asphalt and Deep use 240x320; Constructo uses 128x160.

### Comparison Limits

- Asphalt Instant Play selected different tracks: candidate night Vegas versus
  original daylight. Both show a moving race and HUD, but no speed ratio can
  be inferred. Input was repeated long-press Up through ADB.
- Constructo reaches the same first level on both, but the candidate player is
  already **DOWN** in the timed capture while other helicopters keep moving.
  Therefore the workload is not identical. Black cliff sides also occur on
  the original engine; the downed player's dark silhouette is not evidence of
  a new lighting defect.
- Deep is **Deep: Submarine Odyssey, Java**, not Mophun Deep Abyss. Both start
  at the fishing tutorial with boat/station/HUD visible, then receive fourteen
  Right long-presses separated by 600 ms. Both turn away from the station.
  Capture phases, particles and positions are not frame-identical. The
  candidate's lower host-update throughput leaves optimization work; it is
  not visible display pacing loss in these samples.
- Deep PSS samples were about 63-67 MiB candidate versus 58-60 MiB original.
  Three samples per run do not establish long-session memory stability.
- Thermal service reports status 0 **but HAL Ready: false**. This is not proof
  that no throttling occurred or that device temperature was controlled.
- These are short ADB-driven device checks, not physical-controller, audio,
  full-game or sustained-performance acceptance. No universal native parity
  or release readiness is claimed.
