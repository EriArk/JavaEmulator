# Platform device stickers

[View all stickers](contact-sheet.jpg). Each individual file is a transparent WebP. The five library illustrations are Android resources. The optional Dingoo build also packages the A320 and Gemei A330 illustrations from this directory. The optional P/ECE build packages the Aquaplus illustration. The remaining roadmap artwork stays outside the APK.

These are reference-based illustrations of named hardware. The source photographs guided shape, keypad and control placement. A generative tool isolated and re-lit the designs, simplified details and added a die-cut edge. The individual attribution and license entries below apply to the corresponding adaptations. A device representing a runtime does not imply support for every edition or carrier.

For the MRP illustration, the pictured K-Touch E329 has a [documented mythroad game directory](https://beritafajar.blogspot.com/2010/06/k-touch-smart-e329-ponsel-dual-on-cdma.html). The WIPI tile shows the SHOW-branded Yuna’s Haptic variant visible in the source photograph.

The roadmap includes multiple hardware families within single issues. WonderSwan is retained for scope review. Issue [#82](https://github.com/EriArk/JavaEmulator/issues/82) has no identified WGE handset. Issues #90–92 and the other withdrawn candidates are outside the current roadmap.
