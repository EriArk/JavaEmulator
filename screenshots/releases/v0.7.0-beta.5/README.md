# Beta 5 UI and gameplay demo

[Watch or download the video](abyssme-beta5-demo.mp4) — 69 seconds, 2.4 MB,
720 × 826, H.264 at 30 fps, no audio track.

Recorded on November 13, 2026 on a real Retroid Pocket Classic running Android
14 and the official signed **0.7.0-beta.5 / 319 ARM64** APK.

The continuous recording shows Grid, List and Gallery library views, platform
tabs, per-game Display / Advanced / Compatibility settings, a Deep Abyss 1.4
(Mophun) level, the in-game Display and Controls panels, and return to the library
without saving the demo session.

The device screen was recorded directly with Android screenrecord. Taps and
controller key events were injected through ADB, with touch indicators enabled.
The MP4 is silent and re-encoded at normal speed for a smaller download; no
screens were recreated. Games and their artwork are user supplied and are not
bundled with AbyssME. No game files are included here.

This is a short demonstration, not a full-game compatibility test or a new
physical-button/audio acceptance result. It does not demonstrate the ARMv7 APK.
See the [release checks](../../../docs/releases/v0.7.0-beta.5-checks.md) for their
separate verification scope.

The exported MP4 was decoded end to end without errors; representative UI,
gameplay and final-library frames were inspected.
