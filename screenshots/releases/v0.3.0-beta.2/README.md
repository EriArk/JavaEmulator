# 0.3.0-beta.2 Retroid Captures

Unmodified screenshots from the final signed code-301 APKs on a Retroid Pocket
Classic (Android 14, 1240x1080), captured on 2026-10-15. These are not mockups.

- `library-grid.png`: mixed Java, Mophun and Symbian library during provisioning.
- `native-import.png`: completed three-item SIS/SISX import queue, not gameplay proof.
- `native-menu.png`: shared menu over 3D miniGolf's language screen.
- `phone-shortcuts.png`: independent Display and Screenshot controls.
- `phone-controls.png`: per-game tactile feedback with a scrollable settings page.
- `phone-gamepad.png`: Ghost Recon title screen with the Gamepad deck; only Menu
  remains visible after hiding both optional shortcuts.

Game images belong to their respective rights holders. Games/firmware are not
included. See the [release check boundaries](../../../docs/releases/v0.3.0-beta.2-checks.md)
before using a screenshot as a compatibility claim. Phone captures here are
landscape on a handheld, not portrait-phone acceptance.
