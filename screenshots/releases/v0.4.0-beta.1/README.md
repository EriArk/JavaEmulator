Unretouched ADB captures of the final signed unified APK, code 306, on Retroid
Pocket Classic / Android 14, 2026-10-18. Portrait and landscape use the same app.

separately and are not bundled with AbyssME.

  restored Phone game alongside the existing library.
- `02-controls.png`: shared per-game input priority and screen-button settings,
  with touch layout and button styling options.
- `03-touch-preview.png`: Always numeric-keypad trial in portrait with the
  compact Keep/Undo panel. The trial was allowed to expire; Auto and full game
  space were restored. The game is at its main menu, not a gameplay acceptance test.
