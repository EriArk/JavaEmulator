# Beta 7 new-features demo

[Watch or download the video](abyssme-beta7-new-features.mp4) — 40 seconds,
1.25 MB, 720 × 960, H.264 at 30 fps, no audio track.

Recorded on November 14, 2026 on a real Retroid Pocket Classic running Android
14 and the official signed **0.7.0-beta.7 / 321 ARM64** APK.

The video shows the separate global graphics and control profile catalogs,
a graphics profile editor with image presets and geometry, and changing the
active game's graphics profile from xBRZ to CRT through Display → Graphics
profiles → Choose base profile. Keep commits that change. A short Asphalt 3
Street Rules 3D race follows with CRT rendering and the same Gamepad controls.
The persisted game configuration was checked: the graphics assignment changed
to CRT while the control assignment remained Gamepad.

The xBRZ, CRT and Gamepad demo profiles and initial assignments were prepared
before capture; their creation is not shown. Android screenrecord captured the
actual device with ADB-injected touch input and visible touch indicators. The
edit joins selected passages at normal speed, trims navigation/loading pauses
and uses a separate gameplay take. English captions appear beneath the original
screen image. The video is silent; no screens are recreated.

The temporary catalogs, game configuration, two game save files and Android
recording/orientation settings were restored and compared with their backups.
The signed ARM64 Beta 7 app remains installed. Library last-played metadata may
change during ordinary use. Game binaries, save files and firmware are not
included in the public media; game artwork belongs to its respective owners.

This short demonstration does not establish complete-game, physical-button
comfort, audible-output or ARMv7 acceptance. See the separate
[release checks](../../../docs/releases/v0.7.0-beta.7-checks.md).

The final 1185-frame MP4 was decoded end to end without errors. Representative
catalog, editor, assignment, Keep and gameplay frames were inspected, including
captions. Raw recordings, edit timing, encoder metadata and cleanup evidence
remain local under `build/checks/2026-11-14-beta7-demo/`.
