# Beta 6 Screenshots

Unretouched captures from final signed code 305 APKs on a Retroid Pocket
Classic, Android 14, on 2026-10-18. These are app captures, not photographs.
The Phone variant is running on handheld hardware; this is not a separate
physical-phone ergonomics test. Games were installed separately, not bundled.

- `01-handheld-library.png`: existing library after upgrading Beta 5 to Beta 6.
- `02-handheld-speed.png`: per-game speed control while AgeOfEmpires is paused.
- `03-phone-display.png`: Phone portrait Display page, separate FPS and speed.

Source/runtime limits are in [release checks](../../../docs/releases/v0.3.0-beta.6-checks.md).
