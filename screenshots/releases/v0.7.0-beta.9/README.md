# Beta 9 right-stick demo

[Watch or download the video](abyssme-beta9-right-stick.mp4) — 23 seconds,
1.29 MB, 720 × 960, H.264 at 30 fps, no audio track.

Recorded on November 15, 2026 on Retroid Pocket Classic / Android 14 with the
public signed **0.7.0-beta.9 / 323 ARM64** APK. The video shows Identify selecting
right-stick Up, assigning phone key 5, independent left-stick Left, applying the
mapping and a short Asphalt 3 Street Rules 3D race using both input groups.
The saved configuration confirms right Up = 5 and left Left = Left.

The controller is an Android kernel uinput virtual joystick, not physical
sticks. ADB supplies touch input. The custom profile and portrait orientation
were prepared before recording. The edit joins normal-speed passages, trims
idle/loading time and uses a separate gameplay take. Captions sit below the
actual screen image; no app screens are recreated. Game artwork belongs to its
respective owners; game binaries, saves and firmware are not included.

The original game configuration, two save files and Android capture/orientation
settings were restored and compared with backups. Temporary debug packages and
the virtual input device were removed; signed ARM64 Beta 9 remains installed.
Library last-played metadata may change during ordinary use.

The final MP4 decodes end to end without errors; representative UI, gameplay and
caption frames were inspected. Raw captures, timing and cleanup evidence remain
local in `build/checks/2026-11-15-beta9-demo/`. This is a bounded demonstration,
not physical-controller, audible-output or full-game acceptance. See the
[release checks](../../../docs/releases/v0.7.0-beta.9-checks.md).
