# LCD Export and Grid Correction

Local debug build captures, not a public-release gallery. Supersedes the original
repeating-mask appearance in the earlier LCD development captures.

- `mophun-live.png`: corrected fractional-scale grid on Retroid, with controls.
- `mophun-clean.png` / `mophun-lcd.png`: actual game-only gallery exports.
- `java-clean.png` / `java-lcd.png`: actual Java gallery exports from the emulator.
- `native-clean.png` / `native-lcd.png`: actual Symbian/N-Gage gallery exports.

All are unretouched captures or exported PNGs. Startup screens may advance
between captures; these are not guaranteed identical frames. The private Mophun
fixture filename does not establish the game's title. Games/firmware are not
included, and these checks do not establish full-game compatibility.
