# Gallery and restart development captures

Captured October 17, 2026 from unreleased debug builds. These are actual app
screenshots, not mockups or screenshots of the public beta.3 APK.

- `retroid-wide.png`: Wide Gallery on physical Retroid Pocket Classic.
- `retroid-portrait.png`: Portrait Gallery on the same device; controller focus
  remains visible and title areas align.
- `retroid-game-menu.png`: Java game menu with Restart game and confirmation flow.
- `emulator-square.png`: Handheld library in a 720x720 Android emulator at density
  240. This is not a physical RG Cube capture.
- `retroid-snakes-restarted.png`: Snakes main menu after restarting its native session.

The isolated debug collections include existing fallback/legacy artwork. This
batch changes presentation, not automatic image selection. Game artwork belongs
to its respective rights holders. No games or firmware are included here.
