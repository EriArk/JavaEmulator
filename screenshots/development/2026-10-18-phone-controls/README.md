# Phone control appearance (development)

Captured on 2026-10-18 in the Android 15 Phone emulator, 1080x2340 at 440dpi,
using a local debug build after `de744918`. These are real emulator captures,
not concepts or screenshots of the published beta.4 APK.

The app theme is Light. Controls use the new per-game Button theme setting:

- `01-dark-phone-portrait.png`: dark numeric keypad and top shortcuts.
- `02-light-app-dark-controls-setting.png`: light Controls dialog, Dark selected.
- `03-dark-gamepad-portrait.png`: dark gamepad and top shortcuts.
- `04-dark-gamepad-landscape.png`: landscape gamepad.
- `05-dark-phone-landscape.png`: landscape keypad.
- `06-light-phone-portrait.png`: Light control theme for comparison.
- `08-dark-phone-collapsed.png`: game with the shortcut row collapsed.

The game shown is the separately supplied Bounce Tales fixture. No game files
are included. Captures show the game menu and control appearance, not completed
gameplay, physical-phone ergonomics or broad compatibility acceptance.

The top row is explicitly opened in captures 01 and 03-06 to show its styling;
it is normally collapsed and does not reserve space above the game. See the
[check record](../../../docs/checks/2026-10-18-phone-touch-appearance.md).
